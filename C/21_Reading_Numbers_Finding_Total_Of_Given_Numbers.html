Reading Numbers & Finding Total Of Given Numbers


Explanation

The while loop can be used to read multiple numbers from the user and calculate their total. In this program, the user enters 10 numbers one by one. Each number is added to the total variable. After all numbers are entered, the final total of all numbers is displayed.

How It Works?

  • Step 1: Initialize the variable n with 1 and total with 0.
  • Step 2: The while loop checks whether n <= 10.
  • Step 3: Accept a number from the user.
  • Step 4: Add the entered number to the total variable.
  • Step 5: Increase the value of n by 1.
  • Step 6: Repeat the process until 10 numbers are entered.
  • Step 7: Display the final total of all numbers.

Example Program



#include <stdio.h>
#include <conio.h>


main()

{


    int n = 1, total = 0, no;


    clrscr();


    while(n <= 10)

    {


        printf(
        "\n Enter the Number : "
        );


        scanf(
        "%d", &no);


        total = total + no;


        n = n + 1;


    }


    printf(
    "\n Total = %d", total);


    getch();


}
