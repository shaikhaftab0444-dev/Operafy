Conditional Statement (If-Else)

Definition:

The if-else statement is a decision-making statement in C programming. It is used to execute one block of code when a condition is true and another block of code when the condition is false.

Program: Find the Greater of Two Numbers

Explanation: This program accepts two numbers from the user and displays the greater number using the if-else statement. 


#include <stdio.h>
#include <conio.h>

main()
{
    int No1, No2;

    clrscr();

    printf("Enter the First No : ");
    scanf("%d",&No1);

    printf("Enter the Second No : ");
    scanf("%d",&No2);

    if(No1 > No2)
    {
        printf("\nNo 1 is greater");
    }
    else
    {
        printf("\nNo 2 is greater");
    }

    getch();
}

Output:

Enter the First No : 45
Enter the Second No : 25

No 1 is greater
