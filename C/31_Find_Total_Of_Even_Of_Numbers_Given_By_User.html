Find Total of Even Numbers Given by User Using For Loop


Explanation

The for loop can be used to read multiple numbers from the user and maintain a running total of even and odd numbers separately. In this program, the user enters 10 numbers. After each number is entered, the program checks whether it is even or odd. If it is even, the number is added to the even total and the updated even total is displayed immediately. Otherwise, the number is added to the odd total and the updated odd total is displayed.

How It Works?

  • Step 1: Declare the variables n, e, d, and k. Initialize e and d with 0.
  • Step 2: Initialize k with 1 in the for loop.
  • Step 3: The loop checks whether k <= 10.
  • Step 4: Accept a number from the user.
  • Step 5: Check whether the entered number is even using n % 2 == 0.
  • Step 6: If the number is even, add it to the even total and immediately display the updated even total.
  • Step 7: Otherwise, add it to the odd total and immediately display the updated odd total.
  • Step 8: Repeat the process until all 10 numbers are entered.

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    int n, e = 0, d = 0, k;

    clrscr();

    for(k = 1; k <= 10; k++)
    {

        printf("\n Enter the Number ");

        scanf("%d", &n);

        if(n % 2 == 0)
        {

            e = e + n;

            printf("\n Even Number %d", e);

        }

        else
        {

            d = d + n;

            printf("\n Odd Number %d", d);

        }

    }

    getch();

}
