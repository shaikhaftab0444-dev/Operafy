Create A New Text File


Explanation

In C, a file can be created using the fopen() function. The file is opened in "wt" (write text) mode, which creates a new text file. If the file already exists, its previous contents are erased. The fprintf() function is then used to write text into the file.

How It Works?

  • Step 1: Include the stdio.h header file for file handling functions.
  • Step 2: Declare a file pointer using FILE *fp.
  • Step 3: Open the file using fopen("any.txt", "wt").
  • Step 4: Write text into the file using the fprintf() function.
  • Step 5: Close the file using fclose() after writing the data.
  • Step 6: Run the program and check the created any.txt file.

Example Program


#include <stdio.h>

main()
{

    FILE *fp;

    clrscr();

    fp = fopen("any.txt", "wt");

    fprintf(fp, "hello india");

    fprintf(fp, "\n form of Program");

    fclose(fp);

    getch();

}

Output

The file any.txt will be created with the following contents:

hello india
form of Program
