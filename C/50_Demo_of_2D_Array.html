2D Arrays


Explanation

A two-dimensional array is an array that stores data in the form of rows and columns. It is also called a matrix. In C language, a 2D array is declared using two indexes, where the first index represents the row and the second index represents the column.

In this program, a 4 x 4 two-dimensional array is created. The user enters values into the array using nested for loops. After storing the values, another nested loop is used to display the complete matrix.

How It Works?

  • Step 1: Declare a two-dimensional array m[4][4] to store matrix values.
  • Step 2: Use nested for loops to accept values for rows and columns.
  • Step 3: Store each entered value at the specified row and column position.
  • Step 4: Use another nested for loop to display all array elements.
  • Step 5: Print a new line after displaying each row.

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    int m[4][4], k, p;

    clrscr();

    for(k = 0; k <= 3; k++)
    {

        for(p = 0; p <= 3; p++)
        {

            printf("\nEnter any no : ");

            scanf("%d", &m[k][p]);

        }

    }


    for(k = 0; k <= 3; k++)
    {

        for(p = 0; p <= 3; p++)
        {

            printf("%d ", m[k][p]);

        }

        printf("\n");

    }


    getch();

}
