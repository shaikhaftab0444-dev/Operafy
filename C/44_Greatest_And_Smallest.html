Greatest and Smallest in Array


Explanation

An array is used to store multiple values of the same data type. In this program, the user enters 5 numbers into an array. The first element is assumed to be both the greatest and the smallest. A for loop then compares each array element with these values. If a smaller value is found, it becomes the new smallest value. If a larger value is found, it becomes the new greatest value. Finally, the program displays the greatest and smallest numbers.

How It Works?

  • Step 1: Declare an integer array r[5] and the variables s, g, and k.
  • Step 2: Use a for loop to accept 5 numbers from the user and store them in the array.
  • Step 3: Initialize both s and g with the first array element r[0].
  • Step 4: Use another for loop to compare each element with s and g.
  • Step 5: If the current element is smaller than s, update s.
  • Step 6: If the current element is greater than g, update g.
  • Step 7: Display the greatest and smallest values.

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    int r[5], s = 0, g = 0;
    int k;

    clrscr();

    for(k = 0; k <= 4; k++)
    {

        printf("Enter the Number : ");

        scanf("%d", &r[k]);

    }

    s = g = r[0];

    for(k = 0; k <= 4; k++)
    {

        printf("\n %d", r[k]);

        if(s > r[k])
        {

            s = r[k];

        }

        if(g < r[k])
        {

            g = r[k];

        }

    }

    printf("\n Greatest %d", g);

    printf("\n Smallest %d", s);

    getch();

}
