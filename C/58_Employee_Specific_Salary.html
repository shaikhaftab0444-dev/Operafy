Employee Example With Specific Salary


Explanation

An array of structure is used to store multiple employee records. We can apply conditions on structure members to display only specific records according to the given requirement.

In this program, employee details such as employee id, name, and salary are stored using an array of structures. The program checks the salary of each employee and displays only those employees whose salary is greater than 15000.

How It Works?

  • Step 1: Create a structure named employee with members id, name, and salary.
  • Step 2: Create an array of structure e[5] to store multiple employee records.
  • Step 3: Accept details of three employees using a for loop.
  • Step 4: Use another for loop to check each employee's salary.
  • Step 5: If the employee's salary is greater than 15000, display that employee's details.

Example Program


#include <stdio.h>
#include <conio.h>

struct employee
{

    char name[20];

    int id, salary;

};


main()
{

    struct employee e[5];

    int k;

    clrscr();


    for(k = 0; k <= 2; k++)

    {

        printf("Enter the Employee Id : ");

        scanf("%d", &e[k].id);


        printf("Enter the Employee Name : ");

        scanf("%s", e[k].name);


        printf("Enter the Employee Salary : ");

        scanf("%d", &e[k].salary);

    }


    printf("\nId \tName \tSalary");


    for(k = 0; k <= 2; k++)

    {

        if(e[k].salary > 15000)

        {

            printf("\n%d", e[k].id);

            printf("\t%s", e[k].name);

            printf("\t%d", e[k].salary);

        }

    }


    getch();

}
