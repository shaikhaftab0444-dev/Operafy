Arithmetic Operations Using scanf() in C

Definition:

The scanf() function in C is used to accept input from the user through the keyboard. It allows users to enter values during program execution instead of using fixed values.

Explanation:

This program accepts two numbers from the user using the scanf() function. It then performs addition, subtraction, multiplication, and division on the entered numbers and displays the results using the printf() function.

Program: Addition of Two Numbers Using scanf()

Explanation: This program accepts two numbers from the user using the scanf() function and displays their sum. 


#include <stdio.h>
#include <conio.h>

main()
{
    int a,b,sum;

    clrscr();

    printf("Enter First Number : ");
    scanf("%d",&a);

    printf("Enter Second Number : ");
    scanf("%d",&b);

    sum = a + b;

    printf("\nAddition = %d",sum);

    getch();
}

Output:

Enter First Number : 12
Enter Second Number : 8

Addition = 20

Program: Arithmetic Operations Using scanf()

Explanation: This program accepts two numbers from the user and performs addition, subtraction, multiplication, and division. 


#include <stdio.h>
#include <conio.h>

main()
{
    int a,b,add,sub,multi,div;

    clrscr();

    printf("Enter The Value Of A : ");
    scanf("%d",&a);

    printf("Enter The Value Of B : ");
    scanf("%d",&b);

    add = a + b;
    sub = a - b;
    multi = a * b;
    div = a / b;

    printf("\nAddition = %d",add);
    printf("\nSubtraction = %d",sub);
    printf("\nMultiplication = %d",multi);
    printf("\nDivision = %d",div);

    getch();
}

Output:

Enter The Value Of A : 20
Enter The Value Of B : 10

Addition = 30
Subtraction = 10
Multiplication = 200
Division = 2
