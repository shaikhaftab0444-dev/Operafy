Table In Function


Explanation

A function can receive a value as a parameter and use it to perform a specific task. In this program, the user-defined function table() accepts a number and prints its multiplication table using a for loop. The same function is called multiple times with different numbers to display different tables.

How It Works?

  • Step 1: Include the required header files stdio.h and conio.h.
  • Step 2: Create a user-defined function table(int no) that accepts a number as a parameter.
  • Step 3: Declare the variable k inside the function.
  • Step 4: Use a for loop to print the multiplication table from 0 to 10.
  • Step 5: In the main() function, call table(4) and table(6).
  • Step 6: The function prints the multiplication tables of both numbers.
  • Step 7: Stop the screen using getch().

Example Program


#include <stdio.h>
#include <conio.h>

void table(int no)
{

    int k;

    for(k = 0; k <= 10; k++)

    {

        printf("\n %d x %d = %d", no, k, k * no);

    }

}

int main()
{

    clrscr();

    table(4);

    table(6);

    getch();

}
