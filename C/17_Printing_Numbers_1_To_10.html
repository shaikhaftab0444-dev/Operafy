Printing Number 1 to 10


Definition:

The while loop is an entry-controlled loop in C programming. It repeatedly executes a block of code as long as the specified condition is true. When the condition becomes false, the loop terminates and the control moves to the next statement after the loop.

How It Works?

  • Step 1: Initialize the loop control variable.
  • Step 2: The while loop checks the specified condition.
  • Step 3: If the condition is true, the statements inside the loop are executed.
  • Step 4: Update the loop control variable.
  • Step 5: The condition is checked again.
  • Step 6: The loop continues until the condition becomes false.

Syntax:

Initialization;

while(condition)
{
    // Statements

    Update;
}

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    int k = 1;

    clrscr();

    while(k <= 10)
    {

        printf("\n%d", k);

        k = k + 1;

    }


    getch();

}
