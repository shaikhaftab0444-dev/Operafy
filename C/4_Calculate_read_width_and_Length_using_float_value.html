Area of Rectangle in C

Definition:

A rectangle is a four-sided shape with opposite sides equal. The area of a rectangle is calculated by multiplying its width by its length.

Formula:

Area = Width × Length

Explanation:

This program accepts the width and length of a rectangle from the user using the scanf() function. Both values are stored as float data type, and the area is calculated using the formula Area = Width × Length.

Program: Calculate Area of Rectangle

Explanation: This program accepts the width and length of a rectangle and calculates its area. 


#include <stdio.h>
#include <conio.h>

main()
{
    float a,w,l;

    clrscr();

    printf("Enter Width of Rectangle : ");
    scanf("%f",&w);

    printf("Enter Length of Rectangle : ");
    scanf("%f",&l);

    a = w * l;

    printf("\nArea of Rectangle = %.2f",a);

    getch();
}

Output:

Enter Width of Rectangle : 5.5
Enter Length of Rectangle : 4.0

Area of Rectangle = 22.00

Program: Calculate Area of Square

Explanation: This program accepts the side of a square and calculates its area using the formula Side × Side.

Program: Calculate Area of Triangle

Explanation: This program accepts the base and height of a triangle and calculates its area using the formula (Base × Height) / 2. 


#include <stdio.h>
#include <conio.h>

main()
{
    float base,height,area;

    clrscr();

    printf("Enter Base : ");
    scanf("%f",&base);

    printf("Enter Height : ");
    scanf("%f",&height);

    area = (base * height) / 2;

    printf("\nArea of Triangle = %.2f",area);

    getch();
}

Output:

Enter Base : 8
Enter Height : 5

Area of Triangle = 20.00
