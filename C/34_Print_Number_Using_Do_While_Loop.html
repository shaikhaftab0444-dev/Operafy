Print Number Using Do While Loop


Explanation

The do while loop is used to execute a block of statements repeatedly until the given condition becomes false. In this program, the loop starts from number 1 and prints numbers up to 10 and vice versa. The statements inside the do block are executed first, and then the condition is checked.

How It Works?

  • Step 1: Declare an integer variable k and initialize it with 1.
  • Step 2: The do block starts execution.
  • Step 3: Display the value of k.
  • Step 4: Increase the value of k by 1.
  • Step 5: Check the condition k <= 10.
  • Step 6: Repeat the loop until the condition becomes false.

Example Program

Print Number 1 To 10


#include <stdio.h>
#include <conio.h>


main()
{


    int k = 1;


    do

    {


        printf("\n %d", k);


        k = k + 1;


    }

    while(k <= 10);


    getch();


}

Print Number 10 To 1



#include <stdio.h>
#include <conio.h>


main()
{


    int k = 10;


    do

    {


        printf("\n %d", k);


        k = k - 1;
