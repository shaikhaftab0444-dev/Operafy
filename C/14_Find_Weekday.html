Find Weekday Using Switch Case in C

Introduction:

The switch statement is a multi-way decision-making statement in C. It allows a program to choose one block of code from multiple options based on the value of an expression.

In this program, the user enters a number between 1 and 7. The program uses the switch statement to display the corresponding weekday.

Definition:

A switch statement compares the value of a variable with different case labels. When a matching case is found, the corresponding block of code is executed. If no case matches, the default block is executed.

Syntax:

switch(expression)
{
    case value1:
        statements;
        break;

    case value2:
        statements;
        break;

    ...

    default:
        statements;
}

Explanation:

  • The program accepts a number from the user.
  • The entered number is stored in an integer variable.
  • The switch statement checks the entered value.
  • If the value matches any case, the corresponding weekday is displayed.
  • The break statement stops execution after the matching case.
  • If the entered number is not between 1 and 7, the default case displays "Not A Valid Weekday".

🔹 Program: Find Weekday Using Switch Case

Explanation: This program accepts a number from 1 to 7 and displays the corresponding weekday using the switch statement. 


#include <stdio.h>
#include <conio.h>

main()
{
    int k;

    clrscr();

    printf("Enter a Number : ");
    scanf("%d",&k);

    switch(k)
    {

        case 1:
            printf("\nMonday");
            break;

        case 2:
            printf("\nTuesday");
            break;

        case 3:
            printf("\nWednesday");
            break;

        case 4:
            printf("\nThursday");
            break;

        case 5:
            printf("\nFriday");
            break;

        case 6:
            printf("\nSaturday");
            break;

        case 7:
            printf("\nSunday");
            break;

        default:
            printf("\nNot A Valid Weekday");

    }

    getch();
}

Output:

Enter a Number : 5

Friday
