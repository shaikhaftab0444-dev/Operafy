Check for Vowels Using Switch Statement in C

Definition:

A vowel is one of the five English letters: A, E, I, O, U (or a, e, i, o, u). If the entered character matches any vowel, the program displays "It's a vowel". Otherwise, it displays "It's not a vowel".

Explanation:

  • The program accepts a single character from the user.
  • The switch statement compares the entered character with each vowel (a, e, i, o, u).
  • If the character matches any vowel, the program displays "It's a vowel".
  • If no case matches, the default statement executes and displays "It's not a vowel".
  • The break statement stops the execution after a matching case is found.

Program: Check for Vowels Using Switch Statement

Explanation: This program accepts a character from the user and checks whether it is a vowel or not using the switch statement. 


#include <stdio.h>
#include <conio.h>

main()
{
    char k;

    clrscr();

    printf("Enter a Character : ");
    scanf(" %c",&k);

    switch(k)
    {
        case 'A':
        case 'E':
        case 'I':
        case 'O':
        case 'U':

            printf("\nIt's a vowel");
            break;

        default:

            printf("\nIt's not a vowel");
    }

    getch();
}

Output:

Enter a Character : A

It's a vowel


Enter a Character : Z

It's not a vowel

#include <stdio.h>
#include <conio.h>

main()
{
    char ch;

        case 'e':
        case 'i':
        case 'o':
        case 'u':

            printf("\nLowercase Vowel");
            break;

        default:

            printf("\nNot a Lowercase Vowel");

}
