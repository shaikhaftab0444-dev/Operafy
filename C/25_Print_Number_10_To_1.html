Print Numbers 10 To 1 Using For Loop


Explanation

The for loop can also be used to print numbers in reverse order. In this program, the loop starts from 10 and continues until 1. During each iteration, the value of the variable k is displayed, and its value is decreased by 1.

How It Works?

  • Step 1: Declare the variable k.
  • Step 2: Initialize k with 10 in the for loop.
  • Step 3: The loop checks whether k >= 1.
  • Step 4: Display the current value of k.
  • Step 5: Decrease the value of k by 1 using k = k - 1.
  • Step 6: Repeat the process until the condition becomes false.

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    int k;

    clrscr();

    for(k = 10; k >= 1; k = k - 1)
    {

        printf("\n %d", k);

    }

    getch();

}
