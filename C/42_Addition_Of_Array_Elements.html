Addition of Array Elements


Explanation

An array can be used to store multiple values of the same data type. In this program, the user enters 5 numbers into an integer array. A second for loop is then used to calculate the sum of all array elements. Finally, the program displays the total of the entered numbers.

How It Works?

  • Step 1: Declare an integer array r[5] and the variables k and total.
  • Step 2: Initialize total with 0.
  • Step 3: Use the first for loop to accept five numbers from the user and store them in the array.
  • Step 4: Use the second for loop to access each array element.
  • Step 5: Add each array element to total.
  • Step 6: After the loop finishes, display the total of all array elements.

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    int r[5], k, total = 0;

    clrscr();

    for(k = 0; k <= 4; k++)
    {

        printf("Enter the Number : ");

        scanf("%d", &r[k]);

    }

    for(k = 0; k <= 4; k++)
    {

        total = total + r[k];

    }

    printf("\nTotal = %d", total);

    getch();

}

Output

Enter the Number : 10
Enter the Number : 20
Enter the Number : 15
Enter the Number : 25
Enter the Number : 30

Total = 100
