Mathematical Table Using Nested For Loop


Explanation

A for loop can be nested inside another for loop to display the multiplication tables of multiple numbers. In this program, the outer for loop controls the table number from 5 to 10, while the inner for loop multiplies each number by the values 1 to 10. The result is displayed in a tabular format.

How It Works?

  • Step 1: Declare the variables k and m.
  • Step 2: Display the heading "Table Of 5 to 10".
  • Step 3: Use the outer for loop to generate table numbers from 5 to 10.
  • Step 4: Use the inner for loop to multiply the current table number by values from 1 to 10.
  • Step 5: Display each multiplication result using the printf() function.
  • Step 6: After completing one table, print a new line to display the next table.
  • Step 7: Repeat the process until all tables from 5 to 10 are displayed.

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    int k, m;

    clrscr();

    printf("Table Of 5 to 10");

    printf("\n\n");

    for(k = 5; k <= 10; k++)
    {

        for(m = 1; m <= 10; m++)
        {

            printf("%d\t", k * m);

        }

        printf("\n");

    }

    getch();

}
