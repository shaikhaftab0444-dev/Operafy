Multiplication Table Formation Number Given By User Using For Loop


Explanation

The for loop is used to generate the multiplication table of a number entered by the user. The program accepts a number from the user and repeats the multiplication process from 1 to 10. Each iteration calculates and displays the multiplication result.

How It Works?

  • Step 1: Declare integer variables k and no.
  • Step 2: Accept a number from the user.
  • Step 3: Initialize k = 1 in the for loop.
  • Step 4: The loop runs until k <= 10.
  • Step 5: Multiply the given number with the value of k.
  • Step 6: Display the multiplication table.
  • Step 7: Increase the value of k by 1 and repeat the process. 


#include <stdio.h>
#include <conio.h>


main()

{


    int
    k, no;


    clrscr();


    printf(
    "\n Enter any no"
    );


    scanf(
    "%d",
    &no);


    for
    (k = 1; k <= 10; k = k + 1)

    {


        printf
        (
        "\n %d * %d = %d",
        no, k, no * k);


    }


    getch
    ();


}
