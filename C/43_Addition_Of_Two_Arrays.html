Addition of Two Arrays


Explanation

Two arrays can be added by adding the corresponding elements of each array. In this program, the user enters 5 elements into the first array r[] and another 5 elements into the second array p[]. A for loop is then used to add the corresponding elements and display the result.

How It Works?

  • Step 1: Declare two integer arrays r[5] and p[5], and the variables k, m, and s.
  • Step 2: Use the first for loop to accept 5 numbers for the first array.
  • Step 3: Use the second for loop to accept 5 numbers for the second array.
  • Step 4: Use the third for loop to add the corresponding elements of both arrays.
  • Step 5: Store the result in the variable s.
  • Step 6: Display the addition of each corresponding pair of elements.

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    int r[5], p[5], s;
    int k, m;

    clrscr();

    s = 0;

    for(k = 0; k <= 4; k++)
    {

        printf("Enter the Number : ");

        scanf("%d", &r[k]);

    }

    for(m = 0; m <= 4; m++)
    {

        printf("\nEnter the Number : ");

        scanf("%d", &p[m]);

    }

    for(m = 0; m <= 4; m++)
    {

        s = r[m] + p[m];

        printf("\nTotal is %d", s);

    }

    getch();

}
