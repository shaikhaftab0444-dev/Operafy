Reading A Program or File


Explanation

In C, an existing file can be read using file handling functions. The fopen() function is used to open the file in "rt" (read text) mode. The fgetc() function reads one character at a time from the file and displays it using printf().

How It Works?

  • Step 1: Declare a file pointer using FILE *fp.
  • Step 2: Declare a character variable ch to store each character read from the file.
  • Step 3: Open the file using fopen("any.txt", "rt") in read mode.
  • Step 4: Use the feof() function to check whether the end of the file is reached.
  • Step 5: Read each character using fgetc().
  • Step 6: Display the file content using printf().
  • Step 7: Close the file after reading the data.

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    FILE *fp;
    char ch;

    clrscr();

    fp = fopen("any.txt", "rt");

    while(!feof(fp))
    {

        ch = fgetc(fp);

        printf("%c", ch);

    }

    fclose(fp);

    getch();

}

Output

Content of any.txt file will be displayed:

hello india
