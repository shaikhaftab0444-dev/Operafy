Create File With Scanf


Explanation

In C, we can create a file and store user input data inside it using file handling functions. In this program, the file is opened using fopen() in "w+" mode, which allows writing data into the file. The scanf() function is used to accept values from the user, and fprintf() writes those values into the file.

How It Works?

  • Step 1: Declare a file pointer using FILE *fp.
  • Step 2: Declare variables to store ID, name, and salary.
  • Step 3: Create and open the file using fopen() in "w+" mode.
  • Step 4: Check whether the file is successfully opened or not.
  • Step 5: Take employee details from the user using scanf().
  • Step 6: Write the entered details into the file using fprintf().
  • Step 7: Close the file using fclose().

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    FILE *fp;

    int id, salary;
    char name[100];

    clrscr();

    fp = fopen("xyz.txt", "w+");

    if(fp == NULL)
    {

        printf("File does Not Exist");

        return;

    }

    printf("\n Enter the ID. : ");

    scanf("%d", &id);

    fprintf(fp, "\n id=%d", id);

    printf("\n Enter the Name : ");

    scanf("%s", name);

    fprintf(fp, "\n Name=%s", name);

    printf("\n Enter the Salary : ");

    scanf("%d", &salary);

    fprintf(fp, "\n Salary=%d", salary);

    fclose(fp);

    getch();

}

Output

Enter the ID. : 101
Enter the Name : Rahul
Enter the Salary : 25000


xyz.txt File Content:

id=101
Name=Rahul
Salary=25000
