Arithmetic Operation Of Two Numbers


Explanation

Functions help us divide a program into smaller, reusable parts. In this program, four user-defined functions are created to perform the basic arithmetic operations: add(), sub(), mul(), and div(). Each function accepts two numbers as parameters, performs the required operation, and displays the result. The division function also checks whether the second number is zero to avoid division by zero.

How It Works?

  • Step 1: Include the required header files stdio.h and conio.h.
  • Step 2: Create four user-defined functions: add(), sub(), mul(), and div().
  • Step 3: Each function accepts two integer parameters.
  • Step 4: Perform addition, subtraction, multiplication, and division inside their respective functions.
  • Step 5: In the div() function, check whether the second number is zero before dividing.
  • Step 6: Call all the functions from the main() function using different values.
  • Step 7: Display the result of each arithmetic operation.

Example Program


#include <stdio.h>
#include <conio.h>

void add(int a, int b)
{
    int k = a + b;
    printf("Addition of Numbers is: %d", k);
}

void sub(int a, int b)
{
    int k = a - b;
    printf("\nSubtraction of Numbers is: %d", k);
}

void mul(int a, int b)
{
    int k = a * b;
    printf("\nMultiplication of Numbers is: %d", k);
}

void div(int a, int b)
{

    if(b != 0)
    {

        int k = a / b;
        printf("\nDivision of Numbers is: %d", k);

    }

    else
    {

        printf("\nError: Division by zero is not allowed.");

    }

}

int main()
{

    clrscr();

    add(10, 20);

    sub(20, 10);

    mul(5, 5);

    div(10, 2);

    div(10, 0);

    getch();

}

Output

Addition of Numbers is: 30
Subtraction of Numbers is: 10
Multiplication of Numbers is: 25
Division of Numbers is: 5
Error: Division by zero is not allowed.
