Transfer The File One Place to Another


Explanation

In C file handling, we can transfer data from one file to another file using file operations. In this program, one file is opened in read mode and another file is opened in write mode. The fgetc() function reads characters from the source file, and the fputc() function writes those characters into the destination file.

How It Works?

  • Step 1: Declare two file pointers for source and destination files.
  • Step 2: Open the first file using fopen() in "rt" mode for reading.
  • Step 3: Open the second file using fopen() in "wt" mode for writing.
  • Step 4: Read each character from the first file using fgetc().
  • Step 5: Write the character into the second file using fputc().
  • Step 6: Continue the process until the end of the file is reached.
  • Step 7: Close both files using fclose().

Example Program


#include <stdio.h>
#include <conio.h>

main()
{

    FILE *fp, *fp2;
    char ch;

    clrscr();

    fp = fopen("file2.c", "rt");

    fp2 = fopen("filenew.c", "wt");

    if(fp == NULL || fp2 == NULL)
    {

        printf("Error opening file(s)");

        return;

    }

    while((ch = fgetc(fp)) != EOF)
    {

        fputc(ch, fp2);

        printf("%c", ch);

    }

    fclose(fp);

    fclose(fp2);

    getch();

}
