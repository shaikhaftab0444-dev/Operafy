Greater Example


Explanation

A function can return a value after performing a calculation. In this program, the user-defined function greater() accepts three numbers as parameters and returns the greatest number using the if-else if statement. The returned value is stored in a variable and displayed using printf().

How It Works?

  • Step 1: Create a function greater(int a, int b, int c) that accepts three integer values.
  • Step 2: Declare the variable g to store the greatest number.
  • Step 3: Compare the three numbers using the if-else if statement.
  • Step 4: Store the greatest number in g.
  • Step 5: Return the value of g using the return statement.
  • Step 6: In the main() function, call the greater() function with different values.
  • Step 7: Store the returned value in variables and display the result.

Example Program


#include <stdio.h>
#include <conio.h>

int greater(int a, int b, int c)
{

    int g;

    if(a > b && a > c)
    {

        g = a;

    }

    else if(b > a && b > c)
    {

        g = b;

    }

    else
    {

        g = c;

    }

    return g;

}

int main()
{

    int a, b;

    clrscr();

    a = greater(3, 6, 9);

    printf("\n %d", a);

    b = greater(15, 16, 19);

    printf("\n %d", b);

    getch();

}

Output

9
19
