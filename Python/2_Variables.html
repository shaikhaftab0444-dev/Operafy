Working with Variables

Variables are used to store data values in Python. They help programmers save and manage information such as numbers, text, and other types of data inside a program.

Variables make programs easier to read, understand, and update. The print() function is used to display variable values on the screen.

Basic Variable Output

a = 10
b = 5

print(a)
print(b)
Output
10
5

Variables with Text

Variables can also store text values called strings. Python allows text and variable values to be printed together in a simple and readable format.

This is useful for displaying names, messages, labels, and other information in programs. 

name = "Ali"
age = 20

print("Name:", name)
print("Age:", age)
Output
Name: Ali
Age: 20

Numbers and Calculations

Python can perform mathematical calculations directly inside the print() function without storing the result in a variable.

This feature is useful for quick calculations and arithmetic operations in programs. 

print(10)
print(5 + 3)
Output
10
8

Data Types Check

Python supports different types of data such as int (integer), float (decimal), and str (string).

The type() function is used to check the data type of a variable. 

a = 10        # integer
b = 2.5       # float
c = "AIT"     # string

print(type(a))
print(type(b))
print(type(c))
Output
<class 'int'>
<class 'float'>
<class 'str'>

Practice Exercises

Task 1: Create two variables: `student_name = 'Rohan'` and `grade = 9`, and print them.

Goal: Practice variable creation and assignment.
💡 Hint: Assign string value to student_name and integer to grade.
💡 Show Solution 
student_name = 'Rohan'
grade = 9
print('Student:', student_name, '| Grade:', grade)
Output
Student: Rohan | Grade: 9
Explanation: Variables store values in memory that can be referenced using variable names.
Task 2: A library has `initial_books = 150`. Add 25 new books and subtract 10 issued books using variables.

Goal: Update variable values.
💡 Hint: Reassign variable with updated arithmetic value.
💡 Show Solution 
initial_books = 150
current_books = initial_books + 25 - 10
print('Current Books:', current_books)
Output
Current Books: 165
Explanation: Variable values can be updated by performing calculations using previous values.
Task 3: Swap the values of two variables `rank1 = 1` and `rank2 = 2` using tuple unpacking.

Goal: Swap variables without temporary variables.
💡 Hint: Use `rank1, rank2 = rank2, rank1` syntax.
💡 Show Solution 
rank1 = 1
rank2 = 2
rank1, rank2 = rank2, rank1
print('Rank 1:', rank1, '| Rank 2:', rank2)
Output
Rank 1: 2 | Rank 2: 1
Explanation: Python evaluates the right side values first and reassigns them to left side variables.
