Object Oriented Programming in Python

OOP is used to create objects and classes in Python.

It helps organize and manage code properly.

Class & Object

A class is a blueprint for creating objects.

Objects are created from classes. 

class Student:
    pass

s1 = Student()

print(s1)
Output
<Student object at 0x0000028C639852B0>

Constructor (__init__)

The __init__() method runs automatically when an object is created.

It initializes object data. 

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

s1 = Student("Ali", 20)

print(s1.name, s1.age)
Output
Ali 20

Instance Methods

Methods are functions inside a class.

They define object behavior. 

class Student:
    def __init__(self, name):
        self.name = name

    def greet(self):
        print("Hello", self.name)

s1 = Student("Ali")
s1.greet()
Output
Hello Ali

Inheritance

Inheritance allows one class to use features of another class.

It supports code reuse. 

class Person:
    def __init__(self, name):
        self.name = name

class Student(Person):
    def show(self):
        print(self.name)

s1 = Student("Ali")
s1.show()
Output
Ali

Encapsulation

Encapsulation hides internal data using private variables.

This improves data security. 

class Bank:
    def __init__(self):
        self.__balance = 1000

    def show_balance(self):
        print(self.__balance)

b = Bank()
b.show_balance()
Output
1000

Polymorphism

Polymorphism allows different objects to use the same method name.

Each object behaves differently. 

class Dog:
    def sound(self):
        print("Bark")

class Cat:
    def sound(self):
        print("Meow")

for animal in [Dog(), Cat()]:
    animal.sound()
Output
Bark
Meow

Real Use (Student System)

OOP is used in student, banking, and management systems.

Classes help manage structured data. 

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def total(self):
        return sum(self.marks)

s1 = Student("Ali", [80, 70, 90])

print(s1.total())
Output
240

Mini Project (Bank System)

OOP can create banking applications with deposit and withdraw features.

It keeps code clean and reusable. 

class BankAccount:
    def __init__(self, name, balance):
        self.name = name
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

    def withdraw(self, amount):
        if amount <= self.balance:
            self.balance -= amount
        else:
            print("Insufficient Balance")

    def show(self):
        print(self.name, self.balance)

acc = BankAccount("Ali", 1000)

acc.deposit(500)
acc.withdraw(300)
acc.show()
Output
Ali 1200

Advantages

OOP improves code reuse and organization.

It makes large projects easier to manage.
