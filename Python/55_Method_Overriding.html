Method Overriding in Python

Method overriding means redefining a parent class method in a child class.

The child method replaces the parent method.

Basic Overriding

A child class can create a method with the same name as the parent.

The child method runs instead of the parent method. 

class Animal:
    def sound(self):
        print("Animal Sound")

class Dog(Animal):
    def sound(self):
        print("Dog Barks")

d = Dog()
d.sound()
Output
Dog Barks

Using super()

The super() function calls the parent class method.

It allows parent and child methods to run together. 

class Animal:
    def sound(self):
        print("Animal Sound")

class Dog(Animal):
    def sound(self):
        super().sound()
        print("Dog Barks")

d = Dog()
d.sound()
Output
Animal Sound
Dog Barks

Multiple Classes Example

Different child classes can override the same parent method.

Each class gives different behavior. 

class Shape:
    def draw(self):
        print("Drawing Shape")

class Circle(Shape):
    def draw(self):
        print("Drawing Circle")

class Square(Shape):
    def draw(self):
        print("Drawing Square")

c = Circle()
s = Square()

c.draw()
s.draw()
Output
Drawing Circle
Drawing Square

Real Use (Login System)

Method overriding is used in login, payment, and management systems.

Child classes can add special features. 

class User:
    def login(self):
        print("User Login")

class Admin(User):
    def login(self):
        print("Admin Login with Extra Security")

u = User()
a = Admin()

u.login()
a.login()
Output
User Login
Admin Login with Extra Security

Polymorphism in Action

Method overriding supports runtime polymorphism.

The same function works differently for different objects. 

def make_sound(animal):
    animal.sound()

class Dog:
    def sound(self):
        print("Bark")

class Cat:
    def sound(self):
        print("Meow")

make_sound(Dog())
make_sound(Cat())
Output
Bark
Meow
✔ Same function → different behavior

Advantages

Method overriding improves flexibility and customization.

It helps build reusable and scalable programs.
