Print Statement in Python

Definition:

The print() function in Python is used to display output on the screen. It is used to show text, numbers, or results to the user.

Explanation:

This topic explains how Python shows output using the print() function. It is the most basic and first step in learning Python programming.

🔹 Program: Basic Output (Hello World)

Explanation: This program starts here and shows how to print a simple message on the screen. It is the first and most basic example of output in Python.

This program ends after displaying the message "Hello World" on the screen. 

print("Hello World")

Output:

Hello World

🔹 Program: Multiple Line Output

Explanation: This program shows how to print multiple lines using separate print() statements.

Each print() prints a new line. This helps display output step by step.

▶ Code:

print("Hello")
print("Welcome to Python")

Output:

Hello
Welcome to Python

Print Numbers in Python

Definition:

Python allows us to print numbers directly and also perform simple calculations inside the print() function.

Explanation:

In this topic, we learn how Python displays numbers and solves basic math inside print(). It helps us see results instantly.

🔹 Program: Printing Numbers and Calculation

Explanation: This program starts here and shows how to print a number and also perform addition inside the print() function.

The first line prints a number directly, and the second line calculates and prints the result. The program ends after showing both outputs. 

print(10)
print(5 + 3)

Output:

10
8

Practice Exercises

Task 1: Print school name 'Greenwood High' and current class 'Grade 10' on two separate lines.

Goal: Practice basic text printing.
💡 Hint: Use two separate print() statements.
💡 Show Solution 
print('School: Greenwood High')
print('Class: Grade 10')
Output
School: Greenwood High
Class: Grade 10
Explanation: Each print() function displays its text argument and moves output to a new line.
Task 2: Print student name 'Aman' followed by 3 subject names on a single line separated by commas.

Goal: Print multiple text items on one line.
💡 Hint: Pass multiple string arguments separated by commas inside print().
💡 Show Solution 
print('Student: Aman -', 'Math,', 'Science,', 'English')
Output
Student: Aman - Math, Science, English
Explanation: Comma-separated arguments inside print() are printed on a single line with space separators.
Task 3: Calculate and print a student's total exam score (85 + 90 + 78) directly inside a print statement.

Goal: Perform basic arithmetic inside print().
💡 Hint: Place addition expression inside print() call.
💡 Show Solution 
print('Total Score:', 85 + 90 + 78)
Output
Total Score: 253
Explanation: Python evaluates math expressions inside print() before displaying the final numeric result.
