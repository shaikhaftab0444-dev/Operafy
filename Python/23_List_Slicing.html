List Slicing in Python

List Slicing is used to access a specific portion of a list in Python. It allows programmers to extract selected elements from a list easily.

The basic slicing syntax is: list[start:end] where the starting index is included and the ending index is excluded.

Basic Slicing

Basic slicing extracts elements between a specified start index and end index.

The element at the ending index is not included in the output. 

numbers = [1, 2, 3, 4, 5]

print(numbers[1:4])
Output
[2, 3, 4]

Slicing from Start

If the starting index is omitted, Python automatically starts slicing from the beginning of the list.

This is useful for extracting the first part of a list. 

numbers = [10, 20, 30, 40]

print(numbers[:3])
Output
[10, 20, 30]

Slicing to End

If the ending index is omitted, slicing continues until the last element of the list.

This helps retrieve all remaining elements from a specific position. 

numbers = [10, 20, 30, 40]

print(numbers[1:])
Output
[20, 30, 40]

Negative Index Slicing

Python supports negative indexing, where counting starts from the end of the list.

Negative slicing is useful for accessing recent or last elements quickly. 

numbers = [1, 2, 3, 4, 5]

print(numbers[-3:])
Output
[3, 4, 5]

Reverse List using Slicing

List slicing can also reverse the order of elements using a negative step value.

This method provides a short and efficient way to reverse lists. 

numbers = [1, 2, 3, 4]

print(numbers[::-1])
Output
[4, 3, 2, 1]

Slicing with Step

The step value controls how elements are selected during slicing.

This example selects every second element from the list. 

numbers = [1, 2, 3, 4, 5, 6]

print(numbers[::2])
Output
[1, 3, 5]

Logic Build (Middle Elements)

List slicing can be used to extract middle portions of a list.

This technique is commonly used in data processing and list manipulation tasks. 

nums = [5, 10, 15, 20, 25]

middle = nums[1:4]

print(middle)
Output
[10, 15, 20]

Real Use (Last 3 Records)

Negative slicing is commonly used in real-world applications to access recent records or latest data entries.

This example retrieves the last three elements from the list. 

data = [100, 200, 300, 400, 500]

last_three = data[-3:]

print(last_three)
Output
[300, 400, 500]
