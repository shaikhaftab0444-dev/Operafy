Keyword Arguments (**kwargs) in Python

**kwargs is used in Python functions to accept multiple keyword arguments dynamically. It allows functions to receive an unlimited number of named values.

The data received through **kwargs is stored in the form of a dictionary, where the key represents the parameter name and the value represents the actual data.

Basic Example

A function using **kwargs can accept multiple keyword arguments without defining them individually.

Python automatically stores all keyword arguments inside a dictionary. 

def show_data(**kwargs):
    print(kwargs)

show_data(name="Ali", age=20)
Output
{'name': 'Ali', 'age': 20}

Access Values

Values inside **kwargs can be accessed using dictionary keys.

This allows programmers to retrieve and use specific data easily. 

def show_data(**kwargs):
    print(kwargs["name"])
    print(kwargs["age"])

show_data(name="Ali", age=20)
Output
Ali
20

Loop Through kwargs

Python allows looping through **kwargs using the items() method.

This helps display all keys and values dynamically without writing separate statements. 

def show_data(**kwargs):
    for key, value in kwargs.items():
        print(key, value)

show_data(name="Ali", age=20, city="Pune")
Output
name Ali
age 20
city Pune

Mix with Normal Arguments

Functions can use normal parameters together with **kwargs.

This combination helps create flexible functions with both fixed and dynamic data. 

def user_info(role, **kwargs):
    print("Role:", role)

    for key, value in kwargs.items():
        print(key, value)

user_info("Admin", name="Ali", age=20)
Output
Role: Admin
name Ali
age 20

Real Use (Dynamic Form Data)

The **kwargs feature is commonly used in forms, APIs, databases, and dynamic data handling systems.

It allows programs to accept different types of user data without changing the function structure. 

def save_user(**data):
    for key, value in data.items():
        print(key, ":", value)

save_user(name="Ali", email="ali@gmail.com", phone="9999")
Output
name : Ali
email : ali@gmail.com
phone : 9999

Advanced: Default Value Handling

The get() method can be used with **kwargs to provide default values when a key is missing.

This prevents errors and makes programs safer and more reliable. 

def user(**kwargs):
    name = kwargs.get("name", "Guest")
    age = kwargs.get("age", 0)

    print(name, age)

user(name="Ali")
Output
Ali 0

Mini Project (User Profile System)

Dynamic profile systems can be created using **kwargs.

This allows programs to store and display flexible user information such as name, age, city, and job details. 

def profile(**data):
    print("User Profile")

    for key, value in data.items():
        print(key, ":", value)

profile(name="Ali", age=20, city="Pune", job="Developer")
Output
User Profile
name : Ali
age : 20
city : Pune
job : Developer

Practice Exercises

Task 1: Define function `display_student_info(**kwargs)` to print key-value pairs of student attributes.

Goal: Accept arbitrary keyword arguments with **kwargs.
💡 Hint: Iterate over `kwargs.items()`.
💡 Show Solution 
def display_student_info(**kwargs):
    for key, value in kwargs.items():
        print(f'{key}: {value}')

display_student_info(name='Zain', class_name='Grade 10', grade='A')
Output
name: Zain
class_name: Grade 10
grade: A
Explanation: The `**kwargs` parameter collects keyword arguments into a Python dictionary.
Task 2: Define function `sum_marks(*args)` accepting variable positional marks and returning total sum using sum().

Goal: Accept arbitrary positional arguments with *args.
💡 Hint: Pass `*args` to `sum()`.
💡 Show Solution 
def sum_marks(*args):
    return sum(args)

print('Total Marks:', sum_marks(80, 85, 90, 95))
Output
Total Marks: 350
Explanation: The `*args` parameter collects variable positional arguments into a Python tuple.
Task 3: Create function `register_student(name, *courses, **details)` combining standard, *args, and **kwargs parameters.

Goal: Combine parameter types in single function definition.
💡 Hint: Place positional params first, followed by *args, then **kwargs.
💡 Show Solution 
def register_student(name, *courses, **details):
    print('Student:', name)
    print('Courses:', courses)
    print('Details:', details)

register_student('Amina', 'Math', 'Physics', age=16, city='Lahore')
Output
Student: Amina
Courses: ('Math', 'Physics')
Details: {'age': 16, 'city': 'Lahore'}
Explanation: Combining standard, `*args`, and `**kwargs` parameters allows highly flexible function interface designs.
