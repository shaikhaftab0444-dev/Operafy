Assignment Operators

Assignment Operators are used to assign values to variables in Python. They help programmers store, update, and modify variable values easily.

Python provides different assignment operators such as simple assignment, add and assign, subtract and assign, multiply and assign, and divide and assign.

Operator Name Purpose Example
= Assignment Assigns a value to a variable. x = 10
+= Add and Assign Adds a value and updates the variable. x += 5 → 15
-= Subtract and Assign Subtracts a value and updates the variable. x -= 3 → 7
*= Multiply and Assign Multiplies the variable and stores the result. x *= 2 → 20
/= Divide and Assign Divides the variable and stores the result. x /= 2 → 5.0

Simple Assignment Operator

The assignment operator (=) is used to assign a value to a variable.

It stores the value on the right side into the variable on the left side. 

a = 10

print("Value of a =", a)
Output
Value of a = 10

Add and Assign Operator (+=)

The += operator adds a value to the existing variable value and stores the updated result back into the same variable.

It is a shortcut method for addition and assignment together. 

a = 10
a += 5

print("Result =", a)
Output
Result = 15

Subtract and Assign Operator (-=)

The -= operator subtracts a value from the existing variable value and updates the variable.

It is commonly used to reduce or decrease values in programs. 

a = 10
a -= 3

print("Result =", a)
Output
Result = 7

Multiply and Assign Operator (*=)

The *= operator multiplies the current variable value by another value and stores the result in the same variable.

This operator is useful for repeated multiplication calculations. 

a = 5
a *= 2

print("Result =", a)
Output
Result = 10

Divide and Assign Operator (/=)

The /= operator divides the current variable value by another value and stores the updated result.

In Python, division assignment usually returns a decimal value. 

a = 10
a /= 2

print("Result =", a)
Output
Result = 5.0

Practice Exercises

Task 1: A student has 50 points. Add 15 bonus points to the variable using `+=` operator and print updated score.

Goal: Apply augmented addition assignment.
💡 Hint: Use `score += 15`.
💡 Show Solution 
score = 50
score += 15
print('Updated Score:', score)
Output
Updated Score: 65
Explanation: The `+=` operator adds the right value to the variable and reassigns the new total.
Task 2: A classroom library doubles its book collection of 25 books using `*=` operator.

Goal: Apply augmented multiplication assignment.
💡 Hint: Use `books *= 2`.
💡 Show Solution 
books = 25
books *= 2
print('Doubled Books:', books)
Output
Doubled Books: 50
Explanation: The `*=` operator multiplies existing variable value by 2 in-place.
Task 3: A total of 100 exam sheets are shared equally among 4 teachers using `/=` operator.

Goal: Apply augmented division assignment.
💡 Hint: Use `sheets /= 4`.
💡 Show Solution 
sheets = 100
sheets /= 4
print('Sheets Per Teacher:', sheets)
Output
Sheets Per Teacher: 25.0
Explanation: The `/=` operator performs division and updates the variable with float quotient.
