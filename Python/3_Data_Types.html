Data Types define the type of value stored in a variable. Every variable in Python belongs to a specific data type such as numbers, text, lists, or boolean values.

Python automatically detects the data type based on the value assigned to the variable. Data types help programmers organize and manage data correctly inside programs.

Basic Data Types

Python provides several built-in data types that are commonly used in programs. Each data type is designed for storing a specific kind of information.

Common data types include integers, decimal numbers, text values, and boolean values.

Check Data Type using type()

The type() function is used to identify the data type of a variable. It helps programmers understand what type of value is stored in memory. 

x = 10
y = 10.5
z = "Hello"

print(type(x))
print(type(y))
print(type(z))
Output
<class 'int'>
<class 'float'>
<class 'str'>

Boolean Type

The bool data type stores only two values: True and False.

Boolean values are commonly used in conditions, comparisons, and decision-making statements. 

a = True
b = False

print(a)
print(b)
Output
True
False

Type Conversion (Casting)

Type Conversion means converting one data type into another data type. Python provides built-in functions such as int(), float(), and str() for conversion.

This feature is useful when working with user input and calculations. 

x = "10"

num = int(x)

print(num + 5)
Output
15

List Data Type

A list is used to store multiple values in a single variable. Lists are ordered, changeable, and allow duplicate values.

Lists are written using square brackets []. 

numbers = [1, 2, 3]

print(numbers)
print(type(numbers))
Output
[1, 2, 3]
<class 'list'>

Tuple Data Type

A tuple is used to store multiple values in a single variable. Tuples are ordered but cannot be changed after creation.

Tuples are written using parentheses (). 

data = (10, 20)

print(data)
print(type(data))
Output
(10, 20)
<class 'tuple'>

Set Data Type

A set is a collection of unique values. Sets do not allow duplicate items and are unordered.

Sets are written using curly brackets {}. 

s = {1, 2, 3}

print(s)
print(type(s))
Output
{1, 2, 3}
<class 'set'>

Dictionary Data Type

A dictionary stores data in the form of key-value pairs. Each value is connected to a unique key.

Dictionaries are useful for storing structured information such as student records and user details. 

student = {"name": "Ali", "age": 20}

print(student)
print(type(student))
Output
{'name': 'Ali', 'age': 20}
<class 'dict'>

Real Use Example

Python programs often use different data types together to store and manage real-world information.

For example, a program may store a student's name as text, marks as a number, and pass status as a boolean value. 

name = "Ali"
marks = 85
passed = True

print(name, marks, passed)
Output
Ali 85 True
