Logical Operators in Python

Logical Operators are used to combine multiple conditions in Python. These operators return the result in the form of True or False.

Logical operators are commonly used in decision-making statements, conditions, loops, and logical comparisons in programs.

Demonstrate AND Operator

The AND operator (and) returns True only if all conditions are true.

If any condition is false, the result will be False. 

a = 10
b = 5

print(a > b and b > 2)
Output
True

Demonstrate OR Operator

The OR operator (or) returns True if at least one condition is true.

It returns False only when all conditions are false. 

a = 10
b = 20

print(a > b or b > a)
Output
True

Demonstrate NOT Operator

The NOT operator (not) is used to reverse the result of a condition. 

a = 10

print(not (a > 5))
Output
False

Practice Exercises

Task 1: Verify if a student's score 82 is greater than 50 AND attendance 80% is greater than 75% using `and`.

Goal: Combine multiple conditions with `and`.
💡 Hint: Use `score > 50 and attendance > 75`.
💡 Show Solution 
score = 82
attendance = 80
is_eligible = score > 50 and attendance > 75
print('Scholarship Eligible:', is_eligible)
Output
Scholarship Eligible: True
Explanation: The `and` operator requires both left and right conditions to be True.
Task 2: Check if a student receives distinction if either Math mark >= 90 OR Science mark >= 90 using `or`.

Goal: Combine conditions with `or` operator.
💡 Hint: Use `math >= 90 or science >= 90`.
💡 Show Solution 
math = 88
science = 92
has_distinction = math >= 90 or science >= 90
print('Distinction Awarded:', has_distinction)
Output
Distinction Awarded: True
Explanation: The `or` operator returns True if at least one of the conditions is True.
Task 3: Invert the boolean status `is_suspended = False` using `not` operator to print `is_active` status.

Goal: Invert boolean expressions with `not`.
💡 Hint: Use `not is_suspended`.
💡 Show Solution 
is_suspended = False
is_active = not is_suspended
print('Student Active Status:', is_active)
Output
Student Active Status: True
Explanation: The `not` operator inverts True to False and False to True.
