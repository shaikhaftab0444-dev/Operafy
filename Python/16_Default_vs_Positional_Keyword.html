Function Arguments in Python

Function Arguments are values passed to a function when it is called. They allow functions to work with different data dynamically.

Python supports different types of arguments such as Positional Arguments, Keyword Arguments, and Default Arguments.

Positional Arguments

In Positional Arguments, values are assigned according to their position in the function call.

The order of arguments is important because changing the order changes the output. 

def greet(name, age):
    print(name, age)

greet("Ali", 20)
Output
Ali 20

Wrong Order Example

If positional arguments are passed in the wrong order, the function will still run, but the output may become incorrect.

This happens because Python matches values based on position, not parameter names. 

def greet(name, age):
    print(name, age)

greet(20, "Ali")
Output
20 Ali

Keyword Arguments

In Keyword Arguments, values are passed using parameter names.

The order of arguments is not important because Python matches values using keywords. 

def greet(name, age):
    print(name, age)

greet(age=20, name="Ali")
Output
Ali 20

Default Arguments

Default Arguments allow functions to use predefined values if no value is passed during the function call.

This makes functions more flexible and easier to use. 

def greet(name="User"):
    print(name)

greet()
greet("Ali")
Output
User
Ali

Mix Example (All Together)

Python functions can use positional, keyword, and default arguments together in a single function.

This combination helps create flexible and reusable functions. 

def user(name, age=18, city="Pune"):
    print(name, age, city)

user("Ali")
user("Ali", 20)
user(name="Ali", city="Mumbai")
Output
Ali 18 Pune
Ali 20 Pune
Ali 18 Mumbai

Important Rules

Python follows specific rules while defining and calling function arguments.

Positional arguments are usually written first, default arguments come after positional arguments, and keyword arguments can be used during function calls.

Real Use (User Registration)

Function arguments are widely used in real-world applications such as registration systems, forms, and data processing programs.

They help programs accept user information in a flexible and organized way. 

def register(name, email, country="India"):
    print(name, email, country)

register("Ali", "ali@gmail.com")
register(name="Sara", email="sara@gmail.com", country="UAE")
Output
Ali ali@gmail.com India
Sara sara@gmail.com UAE

Practice Exercises

Task 1: Define function `calculate_fee(course_name, fee=500)` with default fee $500, and call with 1 and 2 arguments.

Goal: Define default parameter values.
💡 Hint: Set `fee=500` in function parameter list.
💡 Show Solution 
def calculate_fee(course_name, fee=500):
    print('Course:', course_name, '| Fee: $' + str(fee))

calculate_fee('Python')
calculate_fee('Data Science', 800)
Output
Course: Python | Fee: $500
Course: Data Science | Fee: $800
Explanation: Default argument values are used when the caller omits corresponding argument.
Task 2: Call function `student_details(roll_no, name)` using positional arguments in order.

Goal: Pass arguments positionally.
💡 Hint: Pass arguments in order matching parameter definitions.
💡 Show Solution 
def student_details(roll_no, name):
    print('Roll No:', roll_no, '| Name:', name)

student_details(101, 'Farhan')
Output
Roll No: 101 | Name: Farhan
Explanation: Positional arguments bind to parameters based on their exact ordinal positions.
Task 3: Call function `student_details(roll_no, name)` using keyword arguments in reversed order.

Goal: Pass arguments by keyword names.
💡 Hint: Use parameter names `name='Farhan', roll_no=101` during function call.
💡 Show Solution 
def student_details(roll_no, name):
    print('Roll No:', roll_no, '| Name:', name)

student_details(name='Farhan', roll_no=101)
Output
Roll No: 101 | Name: Farhan
Explanation: Keyword arguments allow passing parameters in any order by specifying parameter names explicitly.
