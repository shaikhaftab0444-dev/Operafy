Encapsulation & Polymorphism in Python

Encapsulation protects data inside a class.

Polymorphism allows one method to behave differently.

Encapsulation (Private Variable)

Private variables are hidden using double underscore __.

They cannot be accessed directly outside the class. 

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.__marks = marks   # private

    def get_marks(self):
        return self.__marks

obj = Student("Ali", 90)
print(obj.get_marks())
Output
90

Encapsulation with Setter

Setter methods safely update private data.

Getter methods return private values. 

class Bank:
    def __init__(self):
        self.__balance = 0

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance

acc = Bank()
acc.deposit(500)
print(acc.get_balance())
Output
500

Validation Logic

Encapsulation helps validate data before storing it.

This improves security and accuracy. 

class Age:
    def __init__(self):
        self.__age = 0

    def set_age(self, age):
        if age >= 18:
            self.__age = age
        else:
            print("Invalid Age")

    def get_age(self):
        return self.__age

obj = Age()
obj.set_age(15)
obj.set_age(20)
print(obj.get_age())
Output
Invalid Age
20

Polymorphism

Polymorphism means one function works with different data types.

The same method can behave differently. 

print(len("Hello"))
print(len([1,2,3]))
Output
5
3

Method Overriding

Child classes can change parent methods.

This is a common polymorphism feature. 

class Animal:
    def sound(self):
        print("Animal Sound")

class Dog(Animal):
    def sound(self):
        print("Bark")

obj = Dog()
obj.sound()
Output
Bark

Multiple Classes Same Method

Different classes can use the same method name.

Each class gives different behavior. 

class Cat:
    def speak(self):
        print("Meow")

class Dog:
    def speak(self):
        print("Bark")

animals = [Cat(), Dog()]

for a in animals:
    a.speak()
Output
Meow
Bark

Real Use (Payment System)

class Payment:
    def pay(self):
        pass

class UPI(Payment):
    def pay(self):
        print("Paid via UPI")

class Card(Payment):
    def pay(self):
        print("Paid via Card")

methods = [UPI(), Card()]

for m in methods:
    m.pay()
Output
Paid via UPI
Paid via Card

Mini Project (Bank System)

Encapsulation protects bank balance data safely.

Methods handle deposit and withdraw operations. 

class Bank:
    def __init__(self):
        self.__balance = 1000

    def deposit(self, amt):
        self.__balance += amt

    def withdraw(self, amt):
        if amt <= self.__balance:
            self.__balance -= amt

    def show(self):
        print(self.__balance)

acc = Bank()
acc.deposit(500)
acc.withdraw(300)
acc.show()
Output
1200

Advantages

Encapsulation improves data security.

Polymorphism improves flexibility and reuse.
