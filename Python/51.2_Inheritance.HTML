Inheritance in Python

Inheritance allows one class to use properties and methods of another class.

It supports code reuse and better structure.

Basic Inheritance

A child class can access parent class methods directly.

This avoids rewriting code. 


class Parent:
    def show(self):
        print("Parent Method")

class Child(Parent):
    pass

obj = Child()
obj.show()
Output
Parent Method

Method Overriding

A child class can change parent class methods.

This is called method overriding. 


class Parent:
    def show(self):
        print("Parent")

class Child(Parent):
    def show(self):
        print("Child")

obj = Child()
obj.show()
Output
Child

Using super()

The super() function calls parent class methods.

It helps extend parent functionality. 


class Parent:
    def show(self):
        print("Parent Method")

class Child(Parent):
    def show(self):
        super().show()
        print("Child Method")

obj = Child()
obj.show()
Output
Parent Method
Child Method

Constructor Inheritance

Child classes can inherit parent constructors.

Parent data becomes available in child objects. 


class Parent:
    def __init__(self, name):
        self.name = name

class Child(Parent):
    def display(self):
        print(self.name)

obj = Child("Ali")
obj.display()
Output
Ali

Multiple Inheritance

A class can inherit from multiple parent classes.

This combines features from different classes. 


class A:
    def methodA(self):
        print("A")

class B:
    def methodB(self):
        print("B")

class C(A, B):
    pass

obj = C()
obj.methodA()
obj.methodB()
Output
A
B

Multilevel Inheritance

Inheritance can continue through multiple class levels.

One child can become another parent. 


class A:
    def showA(self):
        print("A")

class B(A):
    def showB(self):
        print("B")

class C(B):
    def showC(self):
        print("C")

obj = C()
obj.showA()
obj.showB()
obj.showC()
Output
A
B
C

Hierarchical Inheritance

Multiple child classes can inherit from one parent class.

Each child shares common features. 


class Parent:
    def show(self):
        print("Parent")

class Child1(Parent):
    pass

class Child2(Parent):
    pass

c1 = Child1()
c2 = Child2()

c1.show()
c2.show()
Output
Parent
Parent

Real Use (Employee System)

Inheritance is used in employee, banking, and school systems.

It helps manage related classes easily. 


class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def show(self):
        print(self.name, self.salary)

class Manager(Employee):
    def bonus(self):
        print(self.salary * 0.2)

obj = Manager("Ali", 50000)
obj.show()
obj.bonus()
Output
Ali 50000
10000.0

Method Resolution Order (MRO)

MRO defines the order Python follows to search methods.

The mro() method shows this order. 


class A: pass
class B(A): pass
class C(B): pass

print(C.mro())
Output
[<class '__main__.C'>, <class '__main__.B'>, <class '__main__.A'>, <class 'object'>]

Advantages

Inheritance improves code reuse and flexibility.

It makes programs cleaner and scalable.

Goal: Build practical skills with Inheritance.

    def __init__(self, name):
        self.name = name

class Employee(Person):
    def __init__(self, name, emp_id):
        super().__init__(name)
        self.emp_id = emp_id

e = Employee('Alice', 101)
print(e.name, e.emp_id)

Alice 101
