Input Programs in Python

Input Programs allow users to enter data while the program is running. Python uses the input() function to take input from the user.

User input makes programs interactive and useful for real-world applications such as calculators, forms, login systems, and data entry programs.

Take Input from User

The input() function is used to accept data from the user through the keyboard. The entered value is stored inside a variable for later use.

This feature helps programs communicate and interact with users dynamically. 

name = input("Enter your name: ")

print("Hello", name)
Output
Hello Ali

Addition of Two Numbers Using Input

Python can take numbers as input from the user and perform mathematical operations such as addition.

The int() function is used to convert input values into integers before calculation. 

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

c = a + b

print("Addition =", c)
Output
Enter first number: 5
Enter second number: 3
Addition = 8

Subtract Two Numbers Using Input

Input values can also be used for subtraction operations in Python programs.

The program accepts two numbers from the user, subtracts them, and displays the result. 

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

result = a - b

print("Subtraction =", result)
Output
Enter first number: 10
Enter second number: 3
Subtraction = 7

Multiply Two Numbers Using Input

Python allows multiplication of numbers entered by the user during program execution.

This type of program is commonly used in calculators and mathematical applications. 

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

result = a * b

print("Multiplication =", result)
Output
Enter first number: 4
Enter second number: 2
Multiplication = 8

Divide Two Numbers Using Input

The division operator is used to divide one number by another using user input values.

The result of division is usually returned as a decimal value in Python. 

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

result = a / b

print("Division =", result)
Output
Enter first number: 10
Enter second number: 2
Division = 5.0

Practice Exercises

Task 1: Prompt user for student name using input() and greet them with 'Welcome [Name]!'.

Goal: Capture user string input.
💡 Hint: Use input() function and store input in variable.
💡 Show Solution 
name = input('Enter student name: ')
print('Welcome', name + '!')
Output
Enter student name: Priya
Welcome Priya!
Explanation: input() pauses execution to capture user input as a string.
Task 2: Ask user to input two subject marks, convert them to int, and print total score.

Goal: Convert user string input to numeric integer.
💡 Hint: Wrap input() calls inside int().
💡 Show Solution 
m1 = int(input('Math Marks: '))
m2 = int(input('Science Marks: '))
total = m1 + m2
print('Total Score:', total)
Output
Math Marks: 85
Science Marks: 90
Total Score: 175
Explanation: Since input() returns strings, int() conversion is required before addition.
Task 3: Prompt user for birth year and calculate age in year 2026.

Goal: Build input-based arithmetic calculation.
💡 Hint: Subtract converted birth year integer from 2026.
💡 Show Solution 
birth_year = int(input('Enter Birth Year: '))
age = 2026 - birth_year
print('Age in 2026:', age)
Output
Enter Birth Year: 2008
Age in 2026: 18
Explanation: The program converts typed year to int and subtracts it from 2026.
