String Formatting in Python

String formatting is used to create clean and dynamic text output.

It helps combine variables and text easily.

f-string Formatting

f-string is a modern way to format strings.

Variables are written inside curly brackets {}. 

name = "Ali"
age = 20

result = f"Name: {name}, Age: {age}"

print(result)
Output
Name: Ali, Age: 20

Expressions in f-string

Calculations and expressions can be used inside f-strings.

Python evaluates the result automatically. 

a = 5
b = 3

print(f"Sum = {a + b}")
Output
Sum = 8

Decimal Formatting

Decimal places can be controlled using .2f.

This is useful for prices and float values. 

price = 99.4567

print(f"Price: {price:.2f}")
Output
Price: 99.46

Width & Alignment

Strings can be aligned left, right, or center.

This helps create clean table output. 

name = "Ali"

print(f"{name:<10}")  # Left
print(f"{name:>10}")  # Right
print(f"{name:^10}")  # Center
Output
Ali
Ali
Ali

Padding Values

Numbers can be padded using zeros or spaces.

Example: 7 → 00007 

num = 7

print(f"{num:05}")
Output
00007

Using format() Method

name = "Ali"

print("Hello {}".format(name))
Output
Hello Ali

Multiple Values

Multiple values can be added using format().

This helps build dynamic messages. 

print("{} scored {}".format("Ali", 90))
Output
Ali scored 90

Percentage Formatting

The % symbol is the old string formatting style.

It is still used in some old Python code. 

name = "Ali"

print("Hello %s" % name)
Output
Hello Ali

Real Use (Invoice System)

String formatting is used in bills, invoices, and reports.

It creates clean and readable output. 

item = "Book"
price = 250

print(f"Item: {item} | Price: ₹{price}")
Output
Item: Book | Price: ₹250

Table Formatting

Alignment formatting helps create table-like output.

This is useful for marksheets and records. 

name = "Ali"
marks = 85

print(f"{name:<10} {marks:>5}")
Output
Ali 85

Advantages

String formatting improves readability and presentation.

It makes output professional and organized.
