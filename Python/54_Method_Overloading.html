Method Overloading in Python

Method overloading means using the same method name with different behavior.

Python handles it using special techniques.

Direct Overloading

Python does not support true method overloading directly.

The latest method overrides old methods. 

class Test:

    def add(self, a):
        return a

    def add(self, a, b):
        return a + b

t = Test()
print(t.add(2, 3))
Output
5

Using Default Arguments

Default values allow one method to handle multiple cases.

This creates flexible behavior. 

class Test:

    def add(self, a, b=0):
        return a + b

t = Test()
print(t.add(5))
print(t.add(5, 3))
Output
5
8

Using *args

The *args parameter accepts multiple values.

It is the most common Python overloading style. 

class Test:

    def add(self, *args):
        return sum(args)

t = Test()
print(t.add(2))
print(t.add(2, 3))
print(t.add(2, 3, 4))
Output
2
5
9

Type-Based Logic

Methods can behave differently based on data type.

Functions like isinstance() are used. 

class Test:

    def show(self, value):
        if isinstance(value, int):
            return value * 2
        elif isinstance(value, str):
            return value.upper()

t = Test()
print(t.show(5))
print(t.show("hello"))
Output
10
HELLO

Real Use (Calculator)

Method overloading is useful in calculators and utility systems.

One method can handle many inputs. 

class Calculator:

    def add(self, *args):
        total = 0
        for n in args:
            total += n
        return total

c = Calculator()
print(c.add(1, 2, 3, 4))
Output
10

Advantages

Method overloading improves flexibility and code reuse.

It reduces repeated methods in classes.
