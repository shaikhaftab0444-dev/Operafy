Dictionary Comprehension in Python

Dictionary Comprehension is a short way to create dictionaries in one line.

It uses loops and conditions in a simple format.

Basic Syntax

{key:value for item in iterable}

This syntax creates dictionaries quickly and cleanly.

Basic Example

Dictionary comprehension can map values easily.

Example: number → square value. 

nums = [1, 2, 3]

result = {n: n*n for n in nums}

print(result)
Output
{1: 1, 2: 4, 3: 9}

With Condition

Conditions can be added using if.

This filters selected values only. 

nums = [1, 2, 3, 4]

result = {n: n*n for n in nums if n % 2 == 0}

print(result)
Output
{2: 4, 4: 16}
✔ Sirf even numbers include hue

From String

Strings can also be used in dictionary comprehension.

Example: counting character frequency. 

text = "hello"

result = {ch: text.count(ch) for ch in text}

print(result)
Output
{'h': 1, 'e': 1, 'l': 2, 'o': 1}

List to Dictionary

Lists can be converted into dictionaries easily.

Values can also be transformed during creation. 

names = ["Ali", "Sara"]

result = {name: len(name) for name in names}

print(result)
Output
{'Ali': 3, 'Sara': 4}

Real Use (Pass / Fail)

Dictionary comprehension is useful for result systems and reports.

It helps create pass/fail data quickly. 

marks = {
    "Ali": 80,
    "Sara": 40
}

result = {name: ("Pass" if score >= 50 else "Fail") 
          for name, score in marks.items()}

print(result)
Output
{'Ali': 'Pass', 'Sara': 'Fail'}

Nested Dictionary Comprehension

Dictionary comprehension can also create nested dictionaries.

This is useful for structured data storage. 

nums = [1, 2, 3]

result = {n: {"square": n*n} for n in nums}

print(result)
Output
{1: {'square': 1}, 2: {'square': 4}, 3: {'square': 9}}

Advantages

It reduces code length and improves readability.

It is fast, simple, and efficient.

When to Use

Use dictionary comprehension for quick dictionary creation.

It is useful in filtering and data processing.

Practice Exercises

Task 1: Create a dict mapping numbers 1 through 4 to their cubes `x: x**3` using dict comprehension.

Goal: Practice fundamental Dictionary Comprehension concepts.
💡 Show Solution 
cubes = {x: x ** 3 for x in range(1, 5)}
print(cubes)
Output
{1: 1, 2: 8, 3: 27, 4: 64}
Task 2: Filter a dictionary `{'a': 10, 'b': 50, 'c': 5}` keeping only pairs where value > 15.

Goal: Build practical skills with Dictionary Comprehension.
💡 Show Solution 
scores = {'a': 10, 'b': 50, 'c': 5}
high = {k: v for k, v in scores.items() if v > 15}
print(high)
Output
{'b': 50}
Task 3: Swap keys and values of dictionary `{'x': 1, 'y': 2}` using dict comprehension.

Goal: Deepen your understanding of Dictionary Comprehension.
💡 Show Solution 
d = {'x': 1, 'y': 2}
swapped = {v: k for k, v in d.items()}
print(swapped)
Output
{1: 'x', 2: 'y'}
