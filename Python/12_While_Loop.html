While Loop Programs in Python

While Loop is used to repeat a block of code multiple times as long as a condition remains true. It is one of the most commonly used looping statements in Python.

While loops are useful for repeating tasks, printing patterns, displaying tables, performing calculations, and creating continuous programs.

Print Numbers from 1 to 5

This program uses a while loop to print numbers from 1 to 5 in sequence.

The loop continues until the condition becomes false. 

i = 1

while i <= 5:
    print(i)
    i = i + 1
Output
1
2
3
4
5

Print Name 5 Times

A while loop can also be used to print text repeatedly.

This program prints the same name multiple times using loop repetition. 

i = 1

while i <= 5:
    print("Ali")
    i = i + 1
Output
Ali
Ali
Ali
Ali
Ali

Find Sum from 1 to 5

While loops are commonly used for performing repeated calculations such as finding sums.

The program adds numbers step by step and displays the final result. 

s = 0
i = 1

while i <= 5:
    s = s + i
    i = i + 1

print("Sum =", s)
Output
Sum = 15

Print Table of 2

Loops can be used to generate multiplication tables automatically.

This program prints the table of a number using repeated multiplication. 

i = 1

while i <= 10:
    print(2, "x", i, "=", 2 * i)
    i = i + 1
Output
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
2 x 6 = 12
2 x 7 = 14
2 x 8 = 16
2 x 9 = 18
2 x 10 = 20

Print Reverse Numbers

A while loop can also print numbers in reverse order by decreasing the variable value in each iteration.

This type of loop is useful in countdowns and reverse sequences. 

i = 5

while i >= 1:
    print(i)
    i = i - 1
Output
5
4
3
2
1

Infinite Loop Example

An infinite loop runs continuously because its condition never becomes false.

Infinite loops should be used carefully because they can run forever unless manually stopped. 

while True:
    print("Hello")
Output
Hello
Hello
Hello
...

Practice Exercises

Task 1: Write a while loop to print roll numbers 1 to 5.

Goal: Basic while loop iteration.
💡 Hint: Initialize counter at 1, loop while `roll <= 5`, and increment counter.
💡 Show Solution 
roll = 1
while roll <= 5:
    print('Roll No:', roll)
    roll += 1
Output
Roll No: 1
Roll No: 2
Roll No: 3
Roll No: 4
Roll No: 5
Explanation: The while loop repeats as long as condition `roll <= 5` stays True.
Task 2: Calculate sum of numbers 1 to 10 using a while loop and `total_sum` accumulator.

Goal: Accumulator pattern in while loop.
💡 Hint: Initialize `total_sum = 0` and add counter in each iteration.
💡 Show Solution 
i = 1
total_sum = 0
while i <= 10:
    total_sum += i
    i += 1
print('Total Sum:', total_sum)
Output
Total Sum: 55
Explanation: The accumulator variable collects total sum across repeated loop iterations.
Task 3: Write a countdown while loop from 5 down to 1, then print 'Timer Finished!'.

Goal: Reverse counting with while loop.
💡 Hint: Start counter at 5, loop while `sec >= 1`, and decrement counter.
💡 Show Solution 
sec = 5
while sec >= 1:
    print('Seconds:', sec)
    sec -= 1
print('Timer Finished!')
Output
Seconds: 5
Seconds: 4
Seconds: 3
Seconds: 2
Seconds: 1
Timer Finished!
Explanation: Decrementing counter (`sec -= 1`) guarantees loop condition eventually evaluates to False.
