Tuple Unpacking in Python

Tuple Unpacking is a feature in Python used to assign tuple values directly into multiple variables. It provides a clean and efficient way to extract data from tuples.

Tuple unpacking is widely used in loops, function returns, data processing, swapping values, and record handling.

Basic Unpacking

Basic unpacking assigns tuple elements to variables based on their positions.

The number of variables must match the number of tuple elements. 

t = (10, 20)

a, b = t

print(a, b)
Output
10 20

Unpacking Multiple Values

Python allows unpacking multiple tuple values into separate variables in a single statement.

This technique improves readability and reduces extra indexing operations. 

t = (1, 2, 3, 4)

a, b, c, d = t

print(a, b, c, d)
Output
1 2 3 4

Ignore Values using _

The underscore (_) is commonly used to ignore unwanted tuple values during unpacking.

This helps focus only on required elements. 

t = (5, 10, 15)

a, _, c = t

print(a, c)
Output
5 15

Swap Two Values

Python supports swapping variable values directly using tuple unpacking.

This method is shorter and cleaner than using temporary variables. 

x = 10
y = 50

x, y = y, x

print(x, y)
Output
50 10

Extended Unpacking (*)

The * operator collects multiple remaining values into a list during unpacking.

This feature is useful when handling variable-length data. 

t = (1, 2, 3, 4, 5)

a, *b = t

print(a)
print(b)
Output
1
[2, 3, 4, 5]

First, Middle, Last

Extended unpacking can separate the first and last values while storing middle values together.

This technique is useful for structured data extraction. 

t = (10, 20, 30, 40)

first, *middle, last = t

print(first)
print(middle)
print(last)
Output
10
[20, 30]
40

Unpacking in Loop

Tuple unpacking works directly inside loops for processing grouped data.

This is commonly used when working with pairs and records. 

pairs = [(2, 3), (4, 5)]

for a, b in pairs:
    print(a * b)
Output
6
20

Function Return Unpacking

Functions can return multiple values as tuples.

Tuple unpacking allows these returned values to be stored in separate variables easily. 

def calc():
    return 5, 10

x, y = calc()

print(x + y)
Output
15

Find Maximum & Minimum using Tuple

Python provides built-in functions like max() and min() for tuple data analysis.

These functions help identify the largest and smallest values quickly. 

nums = (10, 5, 20, 3)

mx = max(nums)
mn = min(nums)

print(mx, mn)
Output
20 3

Convert Tuple to List using Unpacking

Tuple unpacking can also be used to convert tuple elements into a list.

This provides flexibility when mutable data handling is required. 

t = (1, 2, 3)

lst = [*t]

print(lst)
Output
[1, 2, 3]

Merge Tuples using Unpacking

The unpacking operator can combine multiple tuples into a single tuple.

This method simplifies tuple merging operations. 

t1 = (1, 2)
t2 = (3, 4)

merged = (*t1, *t2)

print(merged)
Output
(1, 2, 3, 4)

Real Use (Student Records)

Tuple unpacking is commonly used in student management systems, database records, and grouped data processing.

Each tuple stores related data such as student names and marks. 

students = [
    ("Ali", 85),
    ("Sara", 90)
]

for name, marks in students:
    print(name, "scored", marks)
Output
Ali scored 85
Sara scored 90
