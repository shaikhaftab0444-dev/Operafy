Modules in Python

Modules are files containing ready-made functions and tools.

Python provides built-in modules like math and random.

math Module

The math module provides mathematical functions.

It supports square root, rounding, factorial, and more. 

import math

print(math.sqrt(16))
print(math.ceil(4.2))
print(math.floor(4.8))
Output
4.0
5
4

Power & Factorial

Functions like pow() and factorial() perform calculations.

They are useful in maths programs. 

import math

print(math.pow(2, 3))
print(math.factorial(5))
Output
8.0
120

Math Constants

The math module contains constants like pi and e.

These are used in scientific calculations. 

import math

print(math.pi)
print(math.e)
Output
3.141592653589793
2.718281828459045

Real Use (Circle Area)

The math.pi value helps calculate circle area.

It is commonly used in geometry programs. 

import math

r = 5
area = math.pi * r * r

print("Area:", area)
Output
Area: 78.53981633974483

random Module

The random module generates random values.

It is useful in games and OTP systems. 

import random

print(random.randint(1, 10))
Output
9

Random Choice & Shuffle

Functions like choice() and shuffle() work with lists.

They randomly select or arrange items. 

import random

items = ["Pen", "Book", "Bag"]

print(random.choice(items))
Output
Pen

Shuffle List

import random

nums = [1, 2, 3, 4]

random.shuffle(nums)

print(nums)
Output
[3, 1, 2, 4]

Real Use (OTP Generator)

Random numbers are used for OTP and verification systems.

Each run generates different values. 

import random

otp = random.randint(1000, 9999)

print("Your OTP:", otp)
Output
Your OTP: 3205

Mini Project (Guess)

The random module is useful in number guessing games.

Players try to match the secret number. 

import random

secret = random.randint(1, 10)

guess = int(input("Guess: "))

if guess == secret:
    print("Correct!")
else:
    print("Wrong! Number was", secret)
Output
Game Result

Advantages

Modules save time and reduce coding effort.

They provide reusable built-in features.
