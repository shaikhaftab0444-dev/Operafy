File & Folder Management in Python

Python can create, delete, rename, and manage files and folders.

The os and shutil modules are commonly used.

Create Folder

The mkdir() function creates a new folder.

It creates a single directory. 

import os

os.mkdir("my_folder")
print("Folder Created")
Output
Folder Created

Create Multiple Folders

The makedirs() function creates nested folders.

It can create parent and child folders together. 

import os

os.makedirs("parent/child")
print("Nested Folders Created")
Output
Nested Folders Created

Check Folder Exists

The exists() function checks if a folder exists.

It helps avoid errors. 

import os

if os.path.exists("my_folder"):
    print("Exists")
Output
Exists

Rename File

The rename() function changes file names.

It can also rename folders. 

import os

os.rename("old.txt", "new.txt")
Output
File Renamed

Delete File

The remove() function deletes files.

Deleted files cannot be recovered easily. 

import os

os.remove("file.txt")
Output
File Deleted

Delete Folder

The rmdir() function removes empty folders.

It works only if the folder is empty. 

import os

os.rmdir("my_folder")
print("Folder Deleted (Empty only)")
Output
Folder Deleted (Empty only)

Delete Non-Empty Folder

The rmtree() function deletes complete folders.

It removes all files and subfolders. 

import shutil

shutil.rmtree("my_folder")
Output
Folder Deleted Completely

Current Directory

The getcwd() function shows the current folder path.

It helps track working location. 

import os

print(os.getcwd())
Output
C:\Users\HP\OneDrive\Desktop\Working\Python_Final

Change Directory

The chdir() function changes the current directory.

Python starts working inside the new folder. 

import os

os.chdir("my_folder")
Output
Directory Changed

Real Use (Auto File Organizer)

Python can automatically move and organize files.

Useful for downloads and document management. 

import os
import shutil

files = os.listdir()

for f in files:
    if f.endswith(".txt"):
        shutil.move(f, "texts/" + f)

print('All .txt files moved to "texts" folder')
Output
All .txt files moved to "texts" folder

Mini Project (Backup System)

The copytree() function creates folder backups.

It copies all files and subfolders. 

import shutil

shutil.copytree("data", "backup")
Output
Folder Backup Created

Advantages

File and folder management saves time and automates tasks.

It is useful in real-world systems and tools.
