Connect Python with MySQL

Python can connect with MySQL databases using the mysql.connector module.

This connection allows Python programs to manage database data easily.

Import MySQL Connector

First, import the MySQL connector module in Python.

Connection Code

import mysql.connector

db = mysql.connector.connect(

    host="localhost",

    user="root",

    password="",

    database="testdb"

)

print("Connected Successfully")
Output
Connected Successfully

Create Cursor

A cursor object is used to execute SQL queries from Python.

It helps run commands like SELECT, INSERT, UPDATE, and DELETE.

Create Cursor

cursor = db.cursor()
👉 Cursor = Used to execute SQL commands in MySQL
