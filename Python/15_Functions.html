Functions in Python

Functions are reusable blocks of code used to perform specific tasks in a program. Functions help make programs shorter, organized, and easier to manage.

Python uses the def keyword to create functions. Functions can accept input values, perform operations, and return results.

Simple Function

A simple function contains a block of code that runs whenever the function is called.

Functions help avoid writing the same code multiple times. 

def greet():
    print("Hello Student")

greet()
Output
Hello Student

Function with Parameters

Functions can accept input values called parameters.

Parameters allow functions to work with different data values dynamically. 

def add(a, b):
    return a + b

result = add(5, 3)
print(result)
Output
8

Function with Default Value

Python allows functions to use default parameter values.

If no value is passed during the function call, the default value is used automatically. 

def greet(name="User"):
    print("Hello", name)

greet()
greet("Ali")
Output
Hello User
Hello Ali

Function with Default Value (Addition)

Default values can also be used in mathematical functions.

This makes functions flexible and reduces the need to pass values every time. 

def add(a, b=10):
    return a + b

print(add(5))
print(add(5, 20))
Output
15
25

Even / Odd Check Function

Functions can be used with conditional statements to perform logical checks.

This program checks whether a number is even or odd using a function. 

def check_even_odd(num):
    if num % 2 == 0:
        print("Even")
    else:
        print("Odd")

check_even_odd(4)
check_even_odd(7)
Output
Even
Odd

Factorial using Function

A factorial program multiplies numbers from 1 up to a given number.

Functions make mathematical programs more structured and reusable. 

def factorial(n):
    result = 1
    for i in range(1, n+1):
        result = result * i
    return result

print(factorial(5))
Output
120

Return Multiple Values

Python functions can return more than one value at the same time.

Multiple results can be stored in separate variables after the function call. 

def calc(a, b):
    sum = a + b
    diff = a - b
    return sum, diff

s, d = calc(10, 5)

print(s)
print(d)
Output
15
5

Find Largest Number

Functions can also be used to compare values and return the largest number.

This program uses conditional statements inside a function to find the greatest value. 

def find_largest(a, b, c):
    if a > b and a > c:
        return a
    elif b > c:
        return b
    else:
        return c

print(find_largest(10, 25, 15))
Output
25

Practice Exercises

Task 1: Define a function `greet_student(name)` that prints 'Hello [name], welcome to class!'.

Goal: Define and invoke basic functions.
💡 Hint: Use `def greet_student(name):` parameter.
💡 Show Solution 
def greet_student(name):
    print('Hello', name + ', welcome to class!')

greet_student('Amina')
Output
Hello Amina, welcome to class!
Explanation: Parameters allow functions to receive input data dynamically when invoked.
Task 2: Create a function `calculate_grade_avg(m1, m2, m3)` that returns the average score of three exams.

Goal: Return calculated values from functions.
💡 Hint: Use `return (m1 + m2 + m3) / 3`.
💡 Show Solution 
def calculate_grade_avg(m1, m2, m3):
    return (m1 + m2 + m3) / 3

avg = calculate_grade_avg(85, 90, 95)
print('Average Grade:', avg)
Output
Average Grade: 90.0
Explanation: The `return` statement sends the computed result back to the caller.
Task 3: Write a function `check_pass_status(score)` that returns 'Passed' if score >= 50, otherwise 'Failed'.

Goal: Implement conditional logic inside return statements.
💡 Hint: Use an if-else block inside function body.
💡 Show Solution 
def check_pass_status(score):
    if score >= 50:
        return 'Passed'
    else:
        return 'Failed'

print('Score 72:', check_pass_status(72))
print('Score 45:', check_pass_status(45))
Output
Score 72: Passed
Score 45: Failed
Explanation: Functions execute conditional statements internally and return different results based on input values.
