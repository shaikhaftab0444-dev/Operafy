Tuple Programs in Python

A Tuple is an ordered collection data type in Python used to store multiple values in a single variable. Tuples are similar to lists, but they are immutable, which means their values cannot be changed after creation.

Tuples are commonly used for storing fixed data, protecting values from modification, and handling grouped records efficiently.

Create & Print Tuple

A tuple is created using parentheses () with values separated by commas.

The print() function is used to display all tuple elements. 

numbers = (1, 2, 3, 4)

print(numbers)
Output
(1, 2, 3, 4)

Access Tuple Elements

Tuple elements are accessed using index positions.

Indexing starts from 0, where the first element has index position 0. 

numbers = (10, 20, 30)

print(numbers[0])
print(numbers[1])
Output
10
20

Tuple is Immutable

Tuples are immutable, meaning their elements cannot be modified after creation.

If a program tries to change a tuple value, Python generates an error. 

numbers = (1, 2, 3)

numbers[0] = 10
Output
TypeError: 'tuple' object does not support item assignment

Count Elements in Tuple

The len() function is used to count the total number of elements in a tuple.

This function helps determine the size of the tuple. 

numbers = (1, 2, 3, 4)

count = len(numbers)
print(count)
Output
4

Find Maximum in Tuple

The max() function returns the largest value stored in a tuple.

It is commonly used for comparison and data analysis operations. 

numbers = (10, 25, 5)

max_num = max(numbers)
print(max_num)
Output
25

Loop Through Tuple

Loops can be used to access and process tuple elements one by one.

This technique is useful when working with collections of fixed data. 

numbers = (1, 2, 3)

for n in numbers:
    print(n)
Output
1
2
3

Practice Exercises

Task 1: Create a tuple storing college course details `('CS101', 'Python Programming', 4)` representing code, name, and credits. Print all.

Goal: Define and display tuple records.
💡 Hint: Enclose elements in parentheses `()`.
💡 Show Solution 
course = ('CS101', 'Python Programming', 4)
print('Course Code:', course[0])
print('Course Title:', course[1])
print('Credits:', course[2])
Output
Course Code: CS101
Course Title: Python Programming
Credits: 4
Explanation: Tuples group related heterogeneous data fields together in a fixed structure.
Task 2: Demonstrate tuple immutability by catching TypeError when trying to change a student's ID inside tuple `(101, 'Sara')`.

Goal: Understand tuple immutability safety.
💡 Hint: Try assigning `student_tuple[0] = 102` inside a try-except block.
💡 Show Solution 
student_tuple = (101, 'Sara')
try:
    student_tuple[0] = 102
except TypeError:
    print('Error: Tuple elements cannot be modified!')
Output
Error: Tuple elements cannot be modified!
Explanation: Tuples are immutable; their elements cannot be changed, added, or removed after creation.
Task 3: Count occurrences of grade `'A'` in tuple `('A', 'B', 'A', 'C', 'A', 'B')` using `.count()` and find index of `'C'` using `.index()`.

Goal: Use tuple inspection methods.
💡 Hint: Call `tuple.count('A')` and `tuple.index('C')`.
💡 Show Solution 
grades = ('A', 'B', 'A', 'C', 'A', 'B')
print('Total A Grades:', grades.count('A'))
print('Index of C:', grades.index('C'))
Output
Total A Grades: 3
Index of C: 3
Explanation: Tuples provide `.count()` to tally item occurrences and `.index()` to locate first occurrence positions.
