Star Pattern Programs in Python

Star Pattern Programs are used to create different shapes and designs using stars (*) and loops. These programs help beginners understand nested loops and loop logic more clearly.

Pattern programs are commonly used for practicing loop concepts, improving logical thinking, and understanding program flow.

Print Square Star Pattern

This program prints a square pattern using nested for loops.

The outer loop controls the rows, while the inner loop prints stars in each row. 

for i in range(5):
    for j in range(5):
        print("*", end=" ")
    print()
Output
* * * * *
* * * * *
* * * * *
* * * * *
* * * * *

Print Right Triangle Pattern

This program prints a right triangle star pattern.

The number of stars increases in each row using nested loops. 

for i in range(1, 6):
    for j in range(i):
        print("*", end=" ")
    print()
Output
*
* *
* * *
* * * *
* * * * *

Print Reverse Triangle Pattern

A reverse triangle pattern prints stars in decreasing order.

The number of stars reduces in each iteration of the loop. 

for i in range(5, 0, -1):
    for j in range(i):
        print("*", end=" ")
    print()
Output
* * * * *
* * * *
* * *
* *
*

Print Pyramid Pattern

A pyramid pattern combines spaces and stars to create a centered pyramid shape.

This type of pattern helps in understanding spacing, alignment, and nested loop logic. 

for i in range(1, 6):
    print(" " * (5 - i), "*" * (2*i - 1))
Output
*
***
*****
*******
*********

Practice Exercises

Task 1: Print a 4x4 square grid pattern of `#` symbols representing classroom seating arrangement.

Goal: Nested loops for 2D square pattern.
💡 Hint: Use outer and inner loops or string multiplication `print('# ' * 4)`.
💡 Show Solution 
for i in range(4):
    print('# # # #')
Output
# # # #
# # # #
# # # #
# # # #
Explanation: Each loop iteration prints one full row of 4 symbols.
Task 2: Print a right-angled triangle pattern of stars with 4 rows.

Goal: Nested loop pattern with increasing row length.
💡 Hint: Multiply star string `* ` by row index `i` inside range(1, 5).
💡 Show Solution 
for i in range(1, 5):
    print('* ' * i)
Output
*
* *
* * *
* * * *
Explanation: Multiplying string `* ` by loop counter `i` prints increasing number of stars on each line.
Task 3: Print a number pyramid pattern where row `i` prints number `i` repeated `i` times (e.g. Row 1: 1, Row 2: 22, Row 3: 333).

Goal: Generate dynamic numeric row patterns.
💡 Hint: Convert loop variable `i` to str and multiply by `i`.
💡 Show Solution 
for i in range(1, 5):
    print(str(i) * i)
Output
1
22
333
4444
Explanation: Converting number `i` to string allows using string repetition `str(i) * i` to build pattern rows.
