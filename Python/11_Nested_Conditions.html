Nested Conditions in Python

Nested Conditions means using an if statement inside another if statement. This technique is called Nested If.

Nested conditions are used when a program needs to check multiple conditions step by step. They are commonly used in login systems, validations, ATM programs, and decision-making applications.

Basic Nested If

A basic nested if statement checks one condition first and then checks another condition inside it.

The inner condition runs only if the outer condition is true. 

age = 20

if age >= 18:
    if age < 60:
        print("Adult")
Output
Adult

If-Else Inside If

Python allows if-else statements to be placed inside another if block.

This helps programs make more detailed decisions based on multiple conditions. 

num = 10

if num > 0:
    if num % 2 == 0:
        print("Positive Even")
    else:
        print("Positive Odd")
Output
Positive Even

Multiple Nested Levels

Nested conditions can contain multiple levels of if and else statements.

This structure is useful for handling complex decision-making in programs. 

marks = 85

if marks >= 50:
    if marks >= 75:
        print("Distinction")
    else:
        print("Pass")
else:
    print("Fail")
Output
Distinction

Real Use (Login System)

Nested conditions are commonly used in login systems to verify usernames and passwords.

The program first checks the username and then verifies the password. 

username = "admin"
password = "1234"

if username == "admin":
    if password == "1234":
        print("Login Success")
    else:
        print("Wrong Password")
else:
    print("User Not Found")
Output
Login Success

Nested with Input (User Decision)

Python can combine user input with nested conditions to create interactive programs.

This allows programs to make decisions based on user-provided values. 

age = int(input("Enter age: "))

if age >= 18:
    has_id = "yes"

    if has_id == "yes":
        print("Allowed")
    else:
        print("ID Required")
else:
    print("Not Allowed")
Output
Allowed

Shortcut (Avoid Deep Nesting)

In some cases, nested conditions can be simplified using logical operators such as and and or.

This makes the code shorter, cleaner, and easier to understand. 

num = 10

if num > 0 and num % 2 == 0:
    print("Positive Even")
Output
Positive Even

Mini Project (ATM System)

Nested conditions are widely used in real-world applications such as ATM systems and banking programs.

The program first checks the PIN and then verifies whether the account has enough balance for withdrawal. 

pin = 1234
balance = 5000

user_pin = 1234

if user_pin == pin:
    amount = 2000

    if amount <= balance:
        print("Withdraw Success")
    else:
        print("Insufficient Balance")
else:
    print("Wrong PIN")
Output
Withdraw Success

Practice Exercises

Task 1: Check if user is logged into student portal AND has admin rights using nested if statements.

Goal: Nest if statements inside if blocks.
💡 Hint: Place second `if` statement inside first `if` block.
💡 Show Solution 
is_logged_in = True
is_admin = True
if is_logged_in:
    if is_admin:
        print('Access Level: Admin Dashboard')
    else:
        print('Access Level: Student Portal')
else:
    print('Access Level: Guest')
Output
Access Level: Admin Dashboard
Explanation: Inner condition `if is_admin` is evaluated only if outer condition `is_logged_in` is True.

💡 Show Solution 
score = 85
if score >= 50:
    if score >= 75:
        print('Status: Passed with Distinction')
    else:
        print('Status: Passed')
else:
    print('Status: Failed')

Status: Passed with Distinction
Explanation: Nested conditional logic allows step-by-step refinement of decisions.
Task 3: A library borrowing system: Check if student has valid library card, and if valid, check if unpaid fines <= $0 before issuing book.

Goal: Implement multi-stage system validation.
💡 Hint: Nest fine validation inside card validation block.
💡 Show Solution 
has_card = True
unpaid_fines = 0
if has_card:
    if unpaid_fines <= 0:
        print('Book Issued Successfully!')
    else:
        print('Book Issue Denied: Unpaid Fines')
else:
    print('Book Issue Denied: Library Card Required')
Output
Book Issued Successfully!
Explanation: Nested conditions ensure prerequisites are validated before secondary checks are executed.
