Iterators in Python

An Iterator returns data one by one.

It works with the next() function.

Basic Iterator

The iter() function creates an iterator object.

The next() function gets the next value. 

nums = [1, 2, 3]

it = iter(nums)

print(next(it))
print(next(it))
print(next(it))
Output
1
2
3

Iterator in Loop

The for loop uses iterators internally.

It automatically calls iter() and next(). 

nums = [10, 20, 30]

for n in nums:
    print(n)
Output
10
20
30

StopIteration Error

When all values finish, Python raises StopIteration.

It means no more data is available. 

nums = [1, 2]

it = iter(nums)

print(next(it))
print(next(it))
print(next(it))
Output
1
2
StopIteration Error

Manual Loop using while

Iterators can also work with while loops.

try-except handles StopIteration safely. 

nums = [5, 10]

it = iter(nums)

while True:
    try:
        print(next(it))
    except StopIteration:
        break
Output
5
10

Iterator vs Iterable

Lists, tuples, and strings are iterable objects.

An iterator is created using iter().

Iterable: list, tuple, string
Iterator: object with next()

👉 iter(list) → iterator
👉 next(iterator) → next value

Custom Iterator

Custom iterators are created using classes.

They use __iter__() and __next__(). 

class MyNumbers:
    def __iter__(self):
        self.num = 1
        return self

    def __next__(self):
        if self.num <= 5:
            val = self.num
            self.num += 1
            return val
        else:
            raise StopIteration

obj = MyNumbers()

for x in obj:
    print(x)
Output
1
2
3
4
5

Infinite Iterator

Infinite iterators never stop automatically.

They can create infinite loops. 

class Infinite:
    def __iter__(self):
        self.num = 1
        return self

    def __next__(self):
        val = self.num
        self.num += 1
        return val

obj = Infinite()

for i in obj:
    print(i)
Output
1 2 3 4 ... (infinite)

Real Use (File Iterator)

Files use iterators to read data line by line.

This saves memory and improves performance. 

file = open("data.txt")

for line in file:
    print(line)

file.close()
Output
File lines one by one

Mini Project (Even Iterator)

Custom iterators can generate special values like even numbers.

This helps build reusable logic. 

class Even:
    def __iter__(self):
        self.num = 2
        return self

    def __next__(self):
        if self.num <= 10:
            val = self.num
            self.num += 2
            return val
        else:
            raise StopIteration

obj = Even()

for n in obj:
    print(n)
Output
2
4
6
8
10

Advantages

Iterators save memory and process data efficiently.

They are useful for loops and large datasets.
