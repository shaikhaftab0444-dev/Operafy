Custom Exceptions in Python

Custom exceptions are user-defined errors.

They are used for custom validation and rules.

Create Custom Exception

A custom exception is created using a class.

The class inherits from Exception. 

class MyError(Exception):
    pass

print("Custom Exception Created")
Output
Custom Exception Created

Raise Custom Exception

The raise keyword triggers custom errors.

It stops execution when rules fail. 

class AgeError(Exception):
    pass

age = 15

if age < 18:
    raise AgeError("Under Age!")
Output
Error: Under Age!

Handle Custom Exception

Custom exceptions can be handled using try-except.

This prevents program crashes. 

class AgeError(Exception):
    pass

try:
    age = 16
    
    if age < 18:
        raise AgeError("Not Allowed")

except AgeError as e:
    print(e)
Output
Not Allowed

Custom Error Message

Custom messages can describe the error clearly.

This improves debugging and validation. 

class BalanceError(Exception):
    def __init__(self, msg):
        self.msg = msg

balance = 500

if balance < 1000:
    raise BalanceError("Low Balance")
Output
Error: Low Balance

Real Use (Login System)

Custom exceptions are useful in login and security systems.

They help validate passwords and users. 

class LoginError(Exception):
    pass

username = "admin"
password = "1234"

try:
    if password != "admin123":
        raise LoginError("Wrong Password")

except LoginError as e:
    print(e)
Output
Wrong Password

Multiple Custom Exceptions

Programs can use different custom exceptions together.

Each error handles a different condition. 

class AgeError(Exception): pass
class NameError(Exception): pass

name = ""
age = 15

try:
    if name == "":
        raise NameError("Name Required")
    
    if age < 18:
        raise AgeError("Too Young")

except (NameError, AgeError) as e:
    print(e)
Output
Name Required

Advantages

Custom exceptions make programs safer and cleaner.

They improve error handling in real projects.

        raise NegativeValueError('Number must be positive!')

    print(e)
