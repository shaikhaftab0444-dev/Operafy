Variable Scope in Python

Variable scope defines where a variable can be used.

Python supports local, global, and nested scopes.

Local Scope

A local variable is created inside a function.

It works only inside that function. 

def test():
    x = 10
    print(x)

test()
Output
10

Global Scope

A global variable is created outside functions.

It can be accessed anywhere in the program. 

x = 50

def show():
    print(x)

show()
Output
50

Local vs Global

Local variables override global variables inside functions.

Both variables work separately. 

x = 100

def test():
    x = 20
    print(x)

test()
print(x)
Output
20
100

Using global Keyword

The global keyword changes global variables inside functions.

It updates the original value. 

x = 10

def change():
    global x
    x = 30

change()
print(x)
Output
30

Nested Function Scope

Inner functions can access outer function variables.

This is called enclosing scope. 

def outer():
    x = 5

    def inner():
        print(x)

    inner()

outer()
Output
5

Using nonlocal

The nonlocal keyword changes enclosing variables.

It works inside nested functions. 

def outer():
    x = 10

    def inner():
        nonlocal x
        x = 20

    inner()
    print(x)

outer()
Output
20

LEGB Rule

Python searches variables using the LEGB rule.

L → Local
E → Enclosing
G → Global
B → Built-in

Python variable search order:
Local → Enclosing → Global → Built-in

Real Use (Counter System)

Global variables are useful in counters and tracking systems.

Functions can update shared values. 

count = 0

def increment():
    global count
    count += 1

increment()
increment()

print(count)
Output
2

Advantages

Variable scope improves code safety and organization.

It prevents unwanted variable conflicts.
