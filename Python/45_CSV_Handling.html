CSV Handling in Python

CSV stands for Comma Separated Values.

It is used to store table-like data.

Write CSV File

The csv.writer() function writes data into CSV files.

Each row is stored separately. 

import csv

with open("students.csv", "w", newline="") as file:
    writer = csv.writer(file)
    
    writer.writerow(["Name", "Marks"])
    writer.writerow(["Ali", 80])
    writer.writerow(["Sara", 90])
Output
CSV File Created

Read CSV File

The csv.reader() function reads CSV data.

Rows are returned one by one. 

import csv

with open("students.csv", "r") as file:
    reader = csv.reader(file)
    
    for row in reader:
        print(row)
Output
['Name', 'Marks']
['Ali', 80]
['Sara', 90]

Write using Dictionary

The DictWriter class writes dictionary data into CSV files.

Field names are used as column headers. 

import csv

data = [
    {"name": "Ali", "marks": 80},
    {"name": "Sara", "marks": 90}
]

with open("data.csv", "w", newline="") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "marks"])
    
    writer.writeheader()
    writer.writerows(data)
Output
Dictionary Data Saved

Read as Dictionary

The DictReader class reads CSV rows as dictionaries.

Data becomes easy to access using keys. 

import csv

with open("data.csv", "r") as file:
    reader = csv.DictReader(file)
    
    for row in reader:
        print(row["name"], row["marks"])
Output
Ali 80
Sara 90

Filter CSV Data

Conditions can filter CSV records.

Example: find students with marks above 80. 

import csv

with open("data.csv", "r") as file:
    reader = csv.DictReader(file)
    
    for row in reader:
        if int(row["marks"]) > 80:
            print(row["name"])
Output
Sara

Mini Project (Student CSV System)

CSV files can store student records permanently.

New students can be added easily. 

import csv

name = "Ali"
marks = 85

with open("students.csv", "a", newline="") as file:
    writer = csv.writer(file)
    writer.writerow([name, marks])
Output
Student Added

Real Use

CSV files are used in Excel sheets, reports, and databases.

They are useful for data exchange and storage.

Advantages

CSV handling is simple, fast, and lightweight.

It is widely used in real-world applications.
