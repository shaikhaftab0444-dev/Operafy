JSON Handling in Python

JSON is used to store and exchange structured data.

It is commonly used in APIs and web applications.

Convert Python to JSON

The dumps() function converts Python data into JSON format.

It returns JSON as a string. 

import json

data = {"name": "Ali", "age": 20}

json_data = json.dumps(data)

print(json_data)
Output
{"name": "Ali", "age": 20}

Convert JSON to Python

The loads() function converts JSON text into Python data.

It makes JSON data usable in Python. 

import json

json_data = '{"name": "Ali", "age": 20}'

data = json.loads(json_data)

print(data["name"])
Output
Ali

Write JSON to File

The dump() function saves JSON data into a file.

It is useful for permanent data storage. 

import json

data = {"name": "Sara", "age": 22}

with open("data.json", "w") as file:
    json.dump(data, file)
Output
JSON file created

Read JSON from File

The load() function reads JSON data from a file.

It converts file data into Python objects. 

import json

with open("data.json", "r") as file:
    data = json.load(file)

print(data)
Output
{'name': 'Sara', 'age': 22}

Pretty Print JSON

The indent option formats JSON in readable style.

This improves output readability. 

import json

data = {"name": "Ali", "age": 20}

print(json.dumps(data, indent=4))
Output
{
"name": "Ali",
"age": 20
}

List of Objects

JSON can store multiple objects inside lists.

This is useful for user and product data. 

import json

users = [
    {"name": "Ali", "age": 20},
    {"name": "Sara", "age": 22}
]

json_data = json.dumps(users)

print(json_data)
Output
[{"name": "Ali", "age": 20}, {"name": "Sara", "age": 22}]

Real Use (API Data)

APIs mostly send and receive JSON data.

Python can easily process API responses. 

import json

response = '{"status": "success", "data": {"id": 1, "name": "Ali"}}'

data = json.loads(response)

print(data["data"]["name"])
Output
Ali

Mini Project (User Storage)

JSON files can store user records permanently.

Data can be written and read easily. 

import json

user = {"name": "Ali", "age": 20}

with open("users.json", "w") as file:
    json.dump(user, file)

with open("users.json", "r") as file:
    data = json.load(file)

print(data)
Output
{'name': 'Ali', 'age': 20}

Advantages

JSON is lightweight and easy to understand.

It is widely used in modern applications.
