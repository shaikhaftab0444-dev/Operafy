Create First Window

Tkinter windows are created using the Tk() function.

A window is the main screen of every GUI application.

Basic Window Program

The following program creates a simple Tkinter window. 

import tkinter as tk

window = tk.Tk()

window.title("My First App")

window.geometry("400x300")

window.mainloop()
Output

Code Explanation

✔ Tk() → Creates window

✔ title() → Sets window title

✔ geometry() → Sets window size

✔ mainloop() → Keeps window running

Label in Tkinter

A label widget is used to display text inside the window.

Show Text on Window

import tkinter as tk

window = tk.Tk()

label = tk.Label(
    window,
    text="Welcome to Tkinter",
    font=("Arial", 18)
)

label.pack()

window.mainloop()
Output

Real Use

Labels are commonly used for headings, messages, instructions, and form titles in GUI applications.

Tkinter windows are used in calculators, login systems, billing apps, and desktop software.
