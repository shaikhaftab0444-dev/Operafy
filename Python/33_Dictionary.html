Dictionary in Python

Dictionary stores data in key-value pairs.

It is written using curly brackets {}.

Create Dictionary

A dictionary can store multiple values together.

Each value has its own key. 

student = {"name": "Ali", "age": 20}

print(student)
Output
{'name': 'Ali', 'age': 20}

Access Values

Dictionary values are accessed using keys.

Example: student["name"] 

student = {"name": "Ali", "age": 20}

print(student["name"])
Output
Ali

Add / Update Values

New values can be added using a new key.

Existing values can also be updated. 

student = {"name": "Ali"}

student["age"] = 20
student["name"] = "Ahmed"

print(student)
Output
{'name': 'Ahmed', 'age': 20}

Remove Elements

The pop() method removes a value using its key.

It deletes the selected item from the dictionary. 

student = {"name": "Ali", "age": 20}

student.pop("age")
print(student)
Output
{'name': 'Ali'}

Loop Through Dictionary

Loops can access all dictionary keys and values.

This helps display complete dictionary data. 

student = {"name": "Ali", "age": 20}

for key in student:
    print(key, student[key])
Output
name Ali
age 20

Dictionary Length

The len() function counts total items.

It returns the number of key-value pairs. 

student = {"name": "Ali", "age": 20}

print(len(student))
Output
2

Real Use (Student Record)

Dictionaries are used to store student records and user data.

They help organize related information together. 

student = {
    "name": "Ali",
    "marks": [80, 75, 90]
}

total = sum(student["marks"])
print(total)
Output
245

Function with Dictionary

Dictionaries can be passed into functions.

Functions can access and return dictionary values. 

def get_name(data):
    return data["name"]

student = {"name": "Ali"}

print(get_name(student))
Output
Ali

Advantages

Dictionaries are fast and easy to use.

They make data management simple and organized.

Practice Exercises

Task 1: Create a dictionary `student = {'name': 'Tariq', 'roll_no': 15, 'grade': 'A'}`, and print student's name and grade.

Goal: Access dictionary values by keys.
💡 Hint: Use `student['name']` syntax.
💡 Show Solution 
student = {'name': 'Tariq', 'roll_no': 15, 'grade': 'A'}
print('Name:', student['name'])
print('Grade:', student['grade'])
Output
Name: Tariq
Grade: A
Explanation: Dictionaries store data in key-value pairs where values are retrieved using their associated unique keys.
Task 2: Add a new key `'attendance': 92` to dictionary `info = {'name': 'Zara'}` and update `'name'` to `'Zara Khan'`.

Goal: Add and update dictionary entries.
💡 Hint: Assign value to key: `dict['key'] = value`.
💡 Show Solution 
info = {'name': 'Zara'}
info['attendance'] = 92
info['name'] = 'Zara Khan'
print(info)
Output
{'name': 'Zara Khan', 'attendance': 92}
Explanation: Assigning a value to an existing key updates it; assigning to a new key adds a new pair.
Task 3: Store subject marks in a dictionary `marks = {'Math': 85, 'Science': 90, 'English': 78}`. Calculate total and average marks using `.values()`.

Goal: Process dictionary values dynamically.
💡 Hint: Pass `marks.values()` into `sum()` and `len()`.
💡 Show Solution 
marks = {'Math': 85, 'Science': 90, 'English': 78}
total = sum(marks.values())
avg = total / len(marks)
print('Total Marks:', total, '| Average:', round(avg, 2))
Output
Total Marks: 253 | Average: 84.33
Explanation: The `.values()` method returns a collection of all values in the dictionary.
