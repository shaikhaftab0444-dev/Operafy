Set Operations in Python

Set Operations are used to compare, combine, and filter data stored inside sets. Since sets store only unique values, these operations are useful for handling duplicate-free collections.

Set operations are widely used in mathematics, data analysis, search systems, filtering, and comparison-based applications.

Union Operation

The union() method combines elements from multiple sets into a single set.

Duplicate values are automatically removed, keeping only unique elements. 

a = {1, 2, 3}
b = {3, 4, 5}

result = a.union(b)

print(result)
Output
{1, 2, 3, 4, 5}

Intersection Operation

The intersection() method returns only the common elements shared between sets.

This operation is useful for matching and comparison tasks. 

a = {1, 2, 3}
b = {3, 4, 5}

result = a.intersection(b)

print(result)
Output
{3}

Difference Operation

The difference() method returns elements that exist in the first set but not in the second set.

This helps identify unique values from a specific collection. 

a = {1, 2, 3}
b = {3, 4}

result = a.difference(b)

print(result)
Output
{1, 2}

Symmetric Difference Operation

The symmetric_difference() method returns elements that are unique in both sets.

Common elements are removed from the final result. 

a = {1, 2, 3}
b = {3, 4}

result = a.symmetric_difference(b)

print(result)
Output
{1, 2, 4}

Real Use (Student Subjects)

Set operations are commonly used in educational systems, data filtering, and membership analysis.

This example finds common students and combines all students from different subjects. 

math = {"Ali", "Sara", "John"}
science = {"Sara", "John", "Mike"}

print(math.intersection(science))  # common students
print(math.union(science))        # all students
Output
{'John', 'Sara'}
{'Mike', 'John', 'Sara', 'Ali'}
