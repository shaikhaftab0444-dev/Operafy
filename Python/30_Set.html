Set Programs in Python

A Set is an unordered collection data type in Python used to store unique values. Sets automatically remove duplicate elements and provide fast operations for searching and comparisons.

Sets are commonly used in data filtering, duplicate removal, mathematical operations, and membership testing.

Create & Print Set

A set is created using curly braces {} with elements separated by commas.

The print() function is used to display all elements stored in the set. 

numbers = {1, 2, 3, 4}

print(numbers)
Output
{1, 2, 3, 4}

Set Removes Duplicates

Sets automatically remove duplicate values and keep only unique elements.

This feature is useful for cleaning repeated data efficiently. 

numbers = {1, 2, 2, 3, 3}

print(numbers)
Output
{1, 2, 3}

Add Element in Set

The add() method inserts a new element into a set.

If the value already exists, the set does not store it again. 

numbers = {1, 2, 3}

numbers.add(4)
print(numbers)
Output
{1, 2, 3, 4}

Remove Element from Set

The remove() method deletes a specific element from a set.

This operation is useful for managing and updating set data. 

numbers = {1, 2, 3}

numbers.remove(2)
print(numbers)
Output
{1, 3}

Loop Through Set

Loops can be used to access and process set elements one by one.

Since sets are unordered, the output order may vary. 

numbers = {1, 2, 3}

for n in numbers:
    print(n)
Output
1
2
3

Set Union

The union() method combines elements from multiple sets into a single set.

Duplicate values are removed automatically during the union operation. 

a = {1, 2, 3}
b = {3, 4, 5}

result = a.union(b)
print(result)
Output
{1, 2, 3, 4, 5}

Set Intersection

The intersection() method returns only the common elements between sets.

This operation is widely used in comparisons and matching systems. 

a = {1, 2, 3}
b = {2, 3, 4}

result = a.intersection(b)
print(result)
Output
{2, 3}
