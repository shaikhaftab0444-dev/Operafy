Conditional Statements in Python

Conditional Statements are used to make decisions in Python programs. They allow the program to execute different blocks of code based on conditions.

Python uses if, else, and elif statements for decision-making and logical control.

Check Number is Positive

The if statement is used to check whether a condition is true.

If the condition is true, the code inside the if block will execute. 

a = 10

if a > 0:
    print("Positive Number")
Output
Positive Number

Check Even or Odd

Conditional statements can also be used to check whether a number is even or odd.

The modulus operator (%) is commonly used to find the remainder in such programs. 

num = 5

if num % 2 == 0:
    print("Even Number")
else:
    print("Odd Number")
Output
Odd Number

Greater Number Using Input

Python can take input from the user and compare values using conditional statements.

The program checks which number is greater and displays the result. 

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

if a > b:
    print("A is Greater")
else:
    print("B is Greater")
Output
Enter first number: 10
Enter second number: 5
A is Greater

Even or Odd Number (Using Input)

User input values can also be tested using conditions in Python.

This type of program is useful for practicing input handling and logical operations. 

num = int(input("Enter number: "))

if num % 2 == 0:
    print("Even")
else:
    print("Odd")
Output
Enter number: 4
Even

Check Voting Eligibility

Conditional statements are commonly used to check eligibility based on conditions such as age or marks.

In this example, the program checks whether the user's age is 18 or above. 

age = int(input("Enter age: "))

if age >= 18:
    print("You can vote")
else:
    print("You cannot vote")
Output
Enter age: 20
You can vote

Largest of Three Numbers

Python allows multiple conditions to be checked using if, elif, and else statements.

This program compares three numbers and displays the largest value. 

a = 10
b = 20
c = 15

if a > b and a > c:
    print("A is Largest")
elif b > c:
    print("B is Largest")
else:
    print("C is Largest")
Output
B is Largest

Practice Exercises

Task 1: Write an if-else statement checking if score 55 is >= 40 (Passed) or Failed.

Goal: Basic conditional if-else check.
💡 Hint: Use `if score >= 40:`.
💡 Show Solution 
score = 55
if score >= 40:
    print('Result: Passed')
else:
    print('Result: Failed')
Output
Result: Passed
Explanation: Code under `if` executes when condition is True; otherwise `else` runs.
Task 2: Assign grades: >=90 (Grade A), >=75 (Grade B), >=50 (Grade C), else (Fail) using if-elif-else.

Goal: Multi-branch logic with elif.
💡 Hint: Order conditions from highest score threshold to lowest.
💡 Show Solution 
score = 82
if score >= 90:
    print('Grade: A')
elif score >= 75:
    print('Grade: B')
elif score >= 50:
    print('Grade: C')
else:
    print('Grade: Fail')
Output
Grade: B
Explanation: Python evaluates `elif` branches in sequence until finding the first True condition.
Task 3: Check if attendance percentage 80% is >= 75% for exam hall ticket eligibility.

Goal: Evaluate threshold criteria using if-else.
💡 Hint: Use `if attendance >= 75:`.
💡 Show Solution 
attendance = 80
if attendance >= 75:
    print('Hall Ticket: Eligible')
else:
    print('Hall Ticket: Not Eligible')
Output
Hall Ticket: Eligible
Explanation: Relational comparison `>=` evaluates whether attendance meets required threshold.
