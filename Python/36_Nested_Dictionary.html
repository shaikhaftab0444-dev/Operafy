Nested Dictionary in Python

A Nested Dictionary is a dictionary inside another dictionary.

It is used to store real-world structured data.

Create Nested Dictionary

Nested dictionaries can store multiple records together.

Each key contains another dictionary as value. 

students = {
    "s1": {"name": "Ali", "marks": 80},
    "s2": {"name": "Sara", "marks": 90}
}

print(students)
Output
{'s1': {'name': 'Ali', 'marks': 80}, 's2': {'name': 'Sara', 'marks': 90}}

Access Nested Values

Nested values are accessed using multiple keys.

Example: student["s1"]["name"] 

students = {
    "s1": {"name": "Ali", "marks": 80},
    "s2": {"name": "Sara", "marks": 90}
}

print(students["s1"]["name"])
Output
Ali

Loop Through Nested Dictionary

Loops help access all nested records easily.

This is useful for displaying complete data. 

students = {
    "s1": {"name": "Ali", "marks": 80},
    "s2": {"name": "Sara", "marks": 90}
}

for key, value in students.items():
    print(value["name"], value["marks"])
Output
Ali 80
Sara 90

Update Nested Values

Nested dictionary values can be updated anytime.

This helps manage changing data. 

students = {
    "s1": {"name": "Ali", "marks": 80},
    "s2": {"name": "Sara", "marks": 90}
}

students["s1"]["marks"] = 85

print(students["s1"])
Output
{'name': 'Ali', 'marks': 85}

Add New Record

New records can be added using a new key.

This expands the dictionary data. 

students = {
    "s1": {"name": "Ali", "marks": 80},
    "s2": {"name": "Sara", "marks": 90}
}

students["s3"] = {"name": "John", "marks": 70}

print(students)
Output
{'s1': {'name': 'Ali', 'marks': 80}, 's2': {'name': 'Sara', 'marks': 90}, 's3': {'name': 'John', 'marks': 70}}

Search Data

Conditions can search records inside nested dictionaries.

Example: find students with marks above 80. 

students = {
    "s1": {"name": "Ali", "marks": 80},
    "s2": {"name": "Sara", "marks": 90}
}

for s in students.values():
    if s["marks"] > 80:
        print(s["name"])
Output
Sara

Real Use (User System)

Nested dictionaries are used in user systems, APIs, and databases.

They help organize complex data properly. 

users = {
    "u1": {"name": "Ali", "email": "ali@mail.com"},
    "u2": {"name": "Sara", "email": "sara@mail.com"}
}

print(users["u1"]["email"])
Output
ali@mail.com
