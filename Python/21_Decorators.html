Decorators in Python

A Decorator is a special function used to modify or extend the behavior of another function without changing its original code.

Decorators are commonly used for logging, authentication, validation, timing execution, security checks, and performance monitoring.

Basic Function Without Decorator

A normal function executes its code directly when called.

Without decorators, additional functionality must be written manually inside the function. 

def greet():
    print("Hello User")

greet()
Output
Hello User

Simple Decorator

A simple decorator wraps another function inside a wrapper function.

The wrapper can execute additional code before and after the original function call. 

def my_decorator(func):

    def wrapper():
        print("Before Function")
        func()
        print("After Function")

    return wrapper

def greet():
    print("Hello")

greet = my_decorator(greet)

greet()
Output
Before Function
Hello
After Function

@ Decorator Syntax (Clean Way)

Python provides the @decorator_name syntax for applying decorators in a cleaner and simpler way.

This method improves code readability and avoids manual reassignment of functions. 

def my_decorator(func):

    def wrapper():
        print("Before")
        func()
        print("After")

    return wrapper

@my_decorator
def greet():
    print("Hello")

greet()
Output
Before
Hello
After

Decorator with Arguments

Decorators can also work with functions that accept parameters.

The wrapper function receives arguments and passes them to the original function. 

def my_decorator(func):

    def wrapper(name):
        print("Welcome")
        func(name)

    return wrapper

@my_decorator
def greet(name):
    print("Hello", name)

greet("Ali")
Output
Welcome
Hello Ali

Decorator with *args (Flexible)

Using *args and **kwargs makes decorators more flexible.

This allows decorators to work with functions having different numbers of arguments. 

def my_decorator(func):

    def wrapper(*args, **kwargs):
        print("Running...")
        return func(*args, **kwargs)

    return wrapper

@my_decorator
def add(a, b):
    return a + b

print(add(5, 3))
Output
Running...
8

Real Use (Login Check)

Decorators are widely used in authentication and access control systems.

This example checks whether a user is logged in before allowing access to a function. 

is_logged_in = True

def auth(func):

    def wrapper():
        if is_logged_in:
            func()
        else:
            print("Access Denied")

    return wrapper

@auth
def dashboard():
    print("Welcome to Dashboard")

dashboard()
Output
Welcome to Dashboard

Decorator with Return Value

Decorators can also capture and process the return value of a function.

This is useful for logging results, debugging, and monitoring function outputs. 

def logger(func):

    def wrapper(*args):
        result = func(*args)
        print("Result:", result)
        return result

    return wrapper

@logger
def multiply(a, b):
    return a * b

multiply(3, 4)
Output
Result: 12

Decorator with Parameter

Python decorators can accept custom parameters to control their behavior dynamically.

This technique allows reusable decorators with configurable functionality. 

def repeat(n):

    def decorator(func):

        def wrapper():
            for i in range(n):
                func()

        return wrapper

    return decorator

@repeat(3)
def say_hi():
    print("Hi")

say_hi()
Output
Hi
Hi
Hi

Mini Project (Time Execution)

Decorators are commonly used to measure function execution time and performance.

This example calculates how long a function takes to execute using the time module. 

import time

def timer(func):

    def wrapper():
        start = time.time()
        func()
        end = time.time()
        print("Time:", end - start)

    return wrapper

@timer
def task():
    for i in range(1000000):
        pass

task()
Output
Time: 0.0X seconds

Practice Exercises

Task 1: Write a decorator `@log_execution` that prints 'Executing Exam Module...' before running any function.

Goal: Basic decorator structure.
💡 Hint: Define decorator accepting `func`, inner `wrapper`, and return `wrapper`.
💡 Show Solution 
def log_execution(func):
    def wrapper():
        print('Executing Exam Module...')
        func()
    return wrapper

@log_execution
def start_test():
    print('Test Started!')

start_test()
Output
Executing Exam Module...
Test Started!
Explanation: Decorators wrap functions to extend or modify their behavior without editing function code.
Task 2: Write a decorator `@uppercase_result` that converts string return value of `get_student_name()` to uppercase.

Goal: Modify function return values in decorator wrapper.
💡 Hint: Call `func()` inside wrapper and return `result.upper()`.
💡 Show Solution 
def uppercase_result(func):
    def wrapper():
        res = func()
        return res.upper()
    return wrapper

@uppercase_result
def get_student_name():
    return 'priya sharma'

print('Student Name:', get_student_name())
Output
Student Name: PRIYA SHARMA
Explanation: Decorator wrapper intercepts return value of decorated function and transforms it before returning.
Task 3: Write a decorator `@require_passing_grade` that blocks execution if score parameter passed to function is < 50.

Goal: Decorate functions accepting arguments.
💡 Hint: Use `*args, **kwargs` in wrapper function signature.
💡 Show Solution 
def require_passing_grade(func):
    def wrapper(score):
        if score < 50:
            print('Access Denied: Score below 50')
            return None
        return func(score)
    return wrapper

@require_passing_grade
def print_certificate(score):
    print('Certificate Issued for Score:', score)

print_certificate(45)
print_certificate(88)
Output
Access Denied: Score below 50
Certificate Issued for Score: 88
Explanation: Wrappers with `*args` pass arguments dynamically to underlying function after validating conditions.
