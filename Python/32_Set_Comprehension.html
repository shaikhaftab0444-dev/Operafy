Set Comprehension in Python

Set Comprehension is a short way to create sets in one line.

It removes duplicate values automatically.

What is Set Comprehension?

It creates a set using loops inside curly brackets.

It makes code short and clean.

Basic Syntax

{value for item in iterable}

This syntax stores unique values in a set.

Basic Example

Set comprehension can create a set from a list.

Duplicate values are removed automatically. 

nums = [1, 2, 2, 3]

result = {n for n in nums}

print(result)
Output
{1, 2, 3}

Create Squares

It can perform calculations while creating sets.

Example: square values using n*n. 

nums = [1, 2, 3]

result = {n*n for n in nums}

print(result)
Output
{1, 4, 9}

With Condition

Conditions can be added using if.

This helps filter values like even numbers. 

nums = [1, 2, 3, 4]

result = {n for n in nums if n % 2 == 0}

print(result)
Output
{2, 4}

From String

Strings can also be used in set comprehension.

Only unique characters are stored. 

text = "hello"

result = {ch for ch in text}

print(result)
Output
{'l', 'o', 'h', 'e'}

Remove Duplicates

Set comprehension is useful for removing duplicate data.

It keeps only unique values. 

names = ["Ali", "Sara", "Ali"]

unique_names = {name for name in names}

print(unique_names)
Output
{'Ali', 'Sara'}

Using Functions

Functions like len() can be used inside sets.

It stores calculated values easily. 

words = ["apple", "bat", "cat"]

result = {len(w) for w in words}

print(result)
Output
{3, 5}

Practice Exercises

Task 1: Create a set of squares for numbers in `[1, 2, 2, 3, 4]` using set comprehension.

Goal: Practice fundamental Set Comprehension concepts.
💡 Show Solution 
numbers = [1, 2, 2, 3, 4]
sq_set = {x ** 2 for x in numbers}
print(sorted(list(sq_set)))
Output
[1, 4, 9, 16]
Task 2: Create a set comprehension extracting unique vowel characters from string `'abracadabra'`.

Goal: Build practical skills with Set Comprehension.
💡 Show Solution 
text = 'abracadabra'
vowels = {c for c in text if c in 'aeiou'}
print(sorted(list(vowels)))
Output
['a']
Task 3: Filter set elements keeping only numbers divisible by 3 from `range(15)`.

Goal: Deepen your understanding of Set Comprehension.
💡 Show Solution 
div3 = {x for x in range(15) if x % 3 == 0}
print(sorted(list(div3)))
Output
[0, 3, 6, 9, 12]
