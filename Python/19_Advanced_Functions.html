Advanced Functions in Python

Python provides advanced function features such as *args, recursion, and dynamic data handling. These features help programmers write flexible, reusable, and powerful programs.

Advanced functions are commonly used in real-world applications, data processing, automation, calculations, and system development.

*args with Conditional Logic

The *args parameter allows a function to accept multiple values dynamically.

This program uses conditional logic to filter only even numbers from the given values. 

def filter_even(*nums):
    result = []
    for n in nums:
        if n % 2 == 0:
            result.append(n)
    return result

print(filter_even(1,2,3,4,5))
Output
[2, 4]

*args + Sorting Logic (Top Scores)

Functions using *args can also perform sorting operations on multiple values.

This example sorts marks in descending order and returns the top scores. 

def top_scores(*marks):
    sorted_marks = sorted(marks, reverse=True)
    return sorted_marks[:3]

print(top_scores(40,90,75,60,88))
Output
[90, 88, 75]

*args + Error Handling

Python functions can combine *args with error handling techniques.

This helps programs safely process valid numeric values while ignoring invalid data types. 

def safe_sum(*nums):
    total = 0
    for n in nums:
        if isinstance(n, (int, float)):
            total += n
    return total

print(safe_sum(10, "a", 5))
Output
15

Recursion (Fibonacci Series)

Recursion is a technique where a function calls itself repeatedly until a condition is met.

This program generates Fibonacci numbers using recursive function calls. 

def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)

print(fib(6))
Output
8

Recursion (Palindrome Check)

Recursive functions can also be used for string and text processing operations.

This example checks whether a word is a palindrome by comparing characters recursively. 

def is_palindrome(s):
    if len(s) <= 1:
        return True
    if s[0] != s[-1]:
        return False
    return is_palindrome(s[1:-1])

print(is_palindrome("madam"))
Output
True

Recursion + Memoization (Advanced)

Memoization is an optimization technique used with recursion to store previously calculated results.

This improves program performance by avoiding repeated calculations. 

memo = {}

def fib(n):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib(n-1) + fib(n-2)
    return memo[n]

print(fib(10))
Output
55

Real Use (Shopping Cart System)

Advanced functions are widely used in real-world systems such as shopping carts and billing applications.

This program calculates the total price and applies a discount automatically. 

def cart_total(*prices):
    total = 0
    for p in prices:
        total += p
    discount = 0.1 * total
    return total - discount

print(cart_total(100,200,50))
Output
315.0

Practice Exercises

Task 1: Use `map()` and lambda to add 5 grace marks to a list of student marks `[45, 60, 72, 88]`.

Goal: Transform sequence elements using map().
💡 Hint: Pass `lambda x: x + 5` and list to `map()`, then convert to `list()`.
💡 Show Solution 
marks = [45, 60, 72, 88]
grace_marks = list(map(lambda x: x + 5, marks))
print('Updated Marks:', grace_marks)
Output
Updated Marks: [50, 65, 77, 93]
Explanation: The `map()` function applies the transformation lambda to every element in input list.
Task 2: Use `filter()` and lambda to extract all passing scores (>= 50) from `[38, 75, 42, 90, 61]`.

Goal: Filter sequence elements using filter().
💡 Hint: Pass `lambda x: x >= 50` to `filter()`.
💡 Show Solution 
scores = [38, 75, 42, 90, 61]
passed_scores = list(filter(lambda s: s >= 50, scores))
print('Passing Scores:', passed_scores)
Output
Passing Scores: [75, 90, 61]
Explanation: The `filter()` function retains only elements for which the boolean lambda evaluates to True.
Task 3: Use `functools.reduce()` and lambda to calculate total sum of test scores `[15, 20, 25, 30]`.

Goal: Aggregate sequence elements using reduce().
💡 Hint: Import `reduce` from `functools` module.
💡 Show Solution 
from functools import reduce
scores = [15, 20, 25, 30]
total = reduce(lambda a, b: a + b, scores)
print('Total Sum:', total)
Output
Total Sum: 90
Explanation: The `reduce()` function iteratively combines list elements pair by pair into a single aggregate result.
