Closures in Python

A Closure is a special feature in Python where a function is defined inside another function. The inner function can remember and access variables from the outer function even after the outer function has finished execution.

Closures are useful for data hiding, function factories, state management, custom operations, and advanced function handling.

Basic Example

A basic closure is created when an inner function uses a variable from the outer function.

Even after the outer function ends, the inner function still remembers the variable value. 

def outer():
    msg = "Hello"

    def inner():
        print(msg)

    return inner

func = outer()
func()
Output
Hello

Closure with Parameter

Closures can also work with function parameters.

The inner function stores and remembers the parameter value passed to the outer function. 

def greet(name):
    
    def message():
        print("Hello", name)

    return message

f = greet("Ali")
f()
Output
Hello Ali

Multiple Closures

Closures are commonly used to create reusable functions with stored values.

This technique helps functions remember specific data for future operations. 

def calc(x):

    def add(y):
        return x + y

    return add

add5 = calc(5)

print(add5(10))
Output
15

Closure with State (Counter)

Closures can maintain and update variable states using the nonlocal keyword.

The nonlocal keyword allows the inner function to modify variables from the outer function. 

def counter():

    count = 0

    def increment():
        nonlocal count
        count += 1
        print(count)

    return increment

c = counter()

c()
c()
c()
Output
1
2
3

Real Use (Custom Discount System)

Closures are widely used in real-world applications such as billing systems, discount calculators, and pricing logic.

The outer function stores the discount percentage, while the inner function applies the discount to prices. 

def discount(percent):

    def apply(price):
        return price - (price * percent / 100)

    return apply

d10 = discount(10)

print(d10(500))
Output
450.0

Advanced (Function Factory)

Closures can be used to create function factories, where one function generates multiple customized functions.

This technique is useful for creating reusable mathematical and logical operations dynamically. 

def power(n):

    def calc(x):
        return x ** n

    return calc

square = power(2)
cube = power(3)

print(square(4))
print(cube(4))
Output
16
64

Practice Exercises

Task 1: Create a closure function `make_greeeter(school_name)` returning an inner function greeting students of that school.

Goal: Basic closure creation.
💡 Hint: Return inner function referencing outer variable `school_name`.
💡 Show Solution 
def make_greeter(school_name):
    def greet(student_name):
        print('Welcome', student_name, 'to', school_name)
    return greet

greenwood_greet = make_greeter('Greenwood Academy')
greenwood_greet('Aman')
Output
Welcome Aman to Greenwood Academy
Explanation: The inner function retains access to outer variable `school_name` even after outer function exits.
Task 2: Create a closure counter `student_counter()` that generates unique roll numbers sequentially using `nonlocal`.

Goal: State retention with nonlocal variables in closures.
💡 Hint: Declare `nonlocal count` inside inner function.
💡 Show Solution 
def student_counter():
    count = 0
    def next_roll():
        nonlocal count
        count += 1
        return count
    return next_roll

get_roll = student_counter()
print('Roll:', get_roll())
print('Roll:', get_roll())
print('Roll:', get_roll())
Output
Roll: 1
Roll: 2
Roll: 3
Explanation: The `nonlocal` keyword allows inner function to modify variables in enclosing function scope.
Task 3: Create closure function `mark_accumulator()` keeping running total of added student marks.

Goal: Accumulate state inside closure.
💡 Hint: Store `total = 0` in outer scope and add to it inside inner function.
💡 Show Solution 
def mark_accumulator():
    total = 0
    def add_mark(mark):
        nonlocal total
        total += mark
        return total
    return add_mark

acc = mark_accumulator()
print('Total after Exam 1:', acc(45))
print('Total after Exam 2:', acc(50))
Output
Total after Exam 1: 45
Total after Exam 2: 95
Explanation: Closures maintain persistent state across multiple function invocations without global variables.
