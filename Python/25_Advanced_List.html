Advanced Lists in Python

An Advanced List usually refers to nested lists and complex list operations in Python. A nested list means a list containing one or more lists inside it.

Advanced lists are commonly used for handling tables, matrices, student records, reports, and structured collections of data.

Nested List (List inside List)

A nested list stores multiple lists inside a single parent list.

Elements inside nested lists are accessed using multiple indexes. 

data = [
    [1, 2],
    [3, 4]
]

print(data[0][1])
Output
2

Loop Through Nested List

Nested loops are used to access and process elements from nested lists.

The outer loop accesses rows, while the inner loop accesses individual items. 

data = [
    [1, 2],
    [3, 4]
]

for row in data:
    for item in row:
        print(item)
Output
1
2
3
4

Find Sum of Nested List

Nested loops can also perform calculations on all elements inside nested lists.

This example calculates the total sum of all numbers stored in the list. 

data = [
    [1, 2],
    [3, 4]
]

total = 0

for row in data:
    for item in row:
        total += item

print(total)
Output
10

Print Even Numbers from Nested List

Conditional statements can be combined with nested loops to filter specific values.

This example prints only even numbers from the nested list. 

data = [
    [1, 2],
    [3, 4]
]

for row in data:
    for item in row:
        if item % 2 == 0:
            print(item)
Output
2
4

Matrix Style (2D List)

A two-dimensional list is also called a matrix.

Matrices are widely used in mathematics, game development, data science, and table-based applications. 

matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

for row in matrix:
    print(row)
Output
[1, 2, 3]
[4, 5, 6]

Find Maximum Value in Nested List

Nested loops can compare elements to find the largest value in a nested list.

This technique is useful in result analysis and data comparison systems. 

data = [
    [10, 20],
    [5, 40]
]

max_val = 0

for row in data:
    for item in row:
        if item > max_val:
            max_val = item

print(max_val)
Output
40

Real Use (Student Marks Table)

Nested lists are commonly used to store records such as student names and marks.

Each inner list represents a complete record containing multiple values. 

students = [
    ["Ali", 80],
    ["Sara", 90]
]

for s in students:
    print(s[0], "scored", s[1])
Output
Ali scored 80
Sara scored 90

Search in Nested List

Searching operations can also be performed on nested lists using loops and conditions.

This example checks whether a specific value exists inside the nested list. 

data = [
    [1, 2],
    [3, 4]
]

found = False

for row in data:
    for item in row:
        if item == 3:
            found = True

print(found)
Output
True

Goal: Practice fundamental Advanced List Concepts concepts.
💡 Show Solution

cloned = original.copy()
cloned.append(40)
print('Original:', original)
