Exception Handling in Python

Exception handling is used to manage errors in programs.

It prevents program crashes and handles problems safely.

Basic try / except

The try block contains risky code.

The except block handles errors. 

try:
    x = 10 / 0
except:
    print("Error Occurred")
Output
Error Occurred

Handle Specific Errors

Specific exceptions can handle different error types.

Example: ValueError 

try:
    num = int("abc")
except ValueError:
    print("Invalid Number")
Output
Invalid Number

Multiple Exceptions

Python can handle multiple errors separately.

Each exception has its own block. 

try:
    a = 10 / 0
    b = int("abc")
except ZeroDivisionError:
    print("Cannot divide by zero")
except ValueError:
    print("Conversion Error")
Output
Cannot divide by zero

Using else Block

The else block runs if no error occurs.

It is used for successful execution code. 

try:
    num = int("5")
except:
    print("Error")
else:
    print("Success:", num)
Output
Success: 5

Using finally Block

The finally block always runs.

It is useful for cleanup tasks. 

try:
    file = open("data.txt", "r")
except:
    print("File not found")
finally:
    print("Execution Done")
Output
Execution Done

Real Use (User Input)

Exception handling validates user input safely.

It prevents invalid data errors. 

try:
    num = int(input("Enter number: "))
    result = num * 2
    print(result)
except ValueError:
    print("Please enter valid number")
Output
(Depends on user input)

Raise Custom Exception

The raise keyword creates custom errors.

It is useful for custom validation rules. 

age = 15

if age < 18:
    raise Exception("Not Eligible")
Output
Exception: Not Eligible

Advantages

Exception handling improves program safety and stability.

It creates better user experience.
