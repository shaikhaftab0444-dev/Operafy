Abstraction in Python

Abstraction shows important features and hides internal details.

It is mainly used with abstract classes and methods.

Abstract Class

An abstract class acts like a blueprint.

It defines rules for child classes. 

from abc import ABC, abstractmethod

class Shape(ABC):

    @abstractmethod
    def area(self):
        pass

print("Abstract Class Created")
Output
Abstract Class Created

Child Class Implementation

Child classes implement abstract methods with real logic.

This completes the class structure. 

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

class Square(Shape):
    def area(self):
        return 4 * 4

obj = Square()
print(obj.area())
Output
16

Without Implementation ⚠️

A child class must implement all abstract methods.

Otherwise Python raises an error. 

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

class Test(Shape):
    pass

obj = Test()
Output
TypeError: Can't instantiate abstract class Test without an implementation for abstract method 'area'

Multiple Abstract Methods

Abstract classes can contain multiple abstract methods.

Child classes must implement all of them. 

from abc import ABC, abstractmethod

class Animal(ABC):

    @abstractmethod
    def sound(self):
        pass

    @abstractmethod
    def move(self):
        pass

class Dog(Animal):
    def sound(self):
        return "Bark"

    def move(self):
        return "Run"

d = Dog()
print(d.sound(), d.move())
Output
Bark Run

Real Use (Payment System)

Abstraction is used in payment, banking, and login systems.

Different classes follow the same structure. 

from abc import ABC, abstractmethod

class Payment(ABC):

    @abstractmethod
    def pay(self, amount):
        pass

class CardPayment(Payment):
    def pay(self, amount):
        print("Paid", amount, "via Card")

class UpiPayment(Payment):
    def pay(self, amount):
        print("Paid", amount, "via UPI")

p = UpiPayment()
p.pay(500)
Output
Paid 500 via UPI

Advantages

Abstraction improves code structure and security.

It makes large projects easier to manage.
