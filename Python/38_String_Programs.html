String in Python

A String is used to store text data.

Strings are written inside quotes.

Create String

Strings can store words, sentences, and characters.

Example: "Hello World" 

text = "Hello World"

print(text)
Output
Hello World

Access Characters

Characters are accessed using index numbers.

Index starts from 0. 

text = "Python"

print(text[0])
print(text[1])
Output
P
y

String Length

The len() function counts total characters.

It returns the string length. 

text = "Python"

print(len(text))
Output
6

Upper & Lower Case

upper() converts text to uppercase.

lower() converts text to lowercase. 

text = "python"

print(text.upper())
print(text.lower())
Output
PYTHON
python

Check Substring

The in keyword checks if text exists inside a string.

It returns True if found. 

text = "Hello Python"

if "Python" in text:
    print("Found")
Output
Found

Reverse String

Strings can be reversed using slicing.

Example: text[::-1] 

text = "Python"

rev = text[::-1]
print(rev)
Output
nohtyP

Count Vowels

Loops can count vowels inside a string.

This is useful in text processing. 

text = "hello"

count = 0

for ch in text:
    if ch in "aeiou":
        count = count + 1

print(count)
Output
2

Real Use (Email Check)

Strings are used in email validation and user input checking.

They help verify text patterns. 

email = "user@gmail.com"

if "@" in email and ".com" in email:
    print("Valid Email")
else:
    print("Invalid Email")
Output
Valid Email

Function with String

Strings can be passed into functions.

Functions can return modified text easily. 

def greet(name):
    return "Hello " + name

print(greet("Ali"))
Output
Hello Ali

Advantages

Strings are simple and flexible to use.

They are important for text handling in Python.
