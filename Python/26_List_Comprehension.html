List Comprehension in Python

List Comprehension is a short and efficient way to create lists in Python. It allows programmers to generate, filter, and modify list elements using a single line of code.

List comprehensions improve code readability, reduce loop complexity, and make data processing faster and cleaner.

Basic List Comprehension

A basic list comprehension creates a new list by iterating through existing elements.

It works as a shorter alternative to traditional loops. 

numbers = [1, 2, 3, 4]

result = [n for n in numbers]

print(result)
Output
[1, 2, 3, 4]

Square Numbers

List comprehensions can perform mathematical operations while creating lists.

This example generates a new list containing square values of all numbers. 

numbers = [1, 2, 3, 4]

squares = [n * n for n in numbers]

print(squares)
Output
[1, 4, 9, 16]

Filter Even Numbers

Conditional statements can be used inside list comprehensions to filter elements.

This example selects only even numbers from the list. 

numbers = [1, 2, 3, 4, 5]

evens = [n for n in numbers if n % 2 == 0]

print(evens)
Output
[2, 4]

If-Else in List Comprehension

Python allows conditional expressions directly inside list comprehensions.

This technique helps generate customized values based on conditions. 

numbers = [1, 2, 3]

result = ["Even" if n % 2 == 0 else "Odd" for n in numbers]

print(result)
Output
['Odd', 'Even', 'Odd']

Nested List Comprehension

Nested list comprehensions are used to process nested lists or matrices.

This example converts a two-dimensional list into a single flat list. 

matrix = [[1, 2], [3, 4]]

flat = [num for row in matrix for num in row]

print(flat)
Output
[1, 2, 3, 4]

Real Use (Uppercase Names)

List comprehensions are commonly used in text processing and formatting operations.

This example converts all names in the list to uppercase letters. 

names = ["ali", "sara", "john"]

upper = [name.upper() for name in names]

print(upper)
Output
['ALI', 'SARA', 'JOHN']

Real Use (Filter Passed Students)

List comprehensions can filter records based on logical conditions.

This example creates a list containing only passing marks. 

marks = [40, 75, 30, 90]

passed = [m for m in marks if m >= 50]

print(passed)
Output
[75, 90]

Advanced Example (Remove Duplicates)

List comprehensions can also work with sets and other collections.

This example removes duplicate values from a list using the set() function. 

numbers = [1, 2, 2, 3, 3]

unique = [n for n in set(numbers)]

print(unique)
Output
[1, 2, 3]
