Date & Time in Python

Python uses the datetime module to work with dates and time.

It helps manage schedules, logs, and timestamps.

Current Date & Time

The datetime.now() function returns current date and time.

It shows real-time system data. 

from datetime import datetime

now = datetime.now()

print(now)
Output
2026-05-05 12:30:45 (example)

Only Date

The date.today() function returns today's date.

It is useful for daily records. 

from datetime import date

today = date.today()

print(today)
Output
2026-07-26

Only Time

The time() method returns current time only.

It removes the date part. 

from datetime import datetime

time = datetime.now().time()

print(time)
Output
12:30:45 (example)

Format Date

The strftime() function formats date and time.

It creates user-friendly output. 

from datetime import datetime

now = datetime.now()

formatted = now.strftime("%d-%m-%Y %H:%M")

print(formatted)
Output
05-05-2026 12:30

String to Date

The strptime() function converts text into date objects.

It is useful for form and user input data. 

from datetime import datetime

now = datetime.now()

print(now.strftime("%A, %d %B %Y"))
Output
Tuesday, 05 May 2026

String to Date

The strptime() function converts text into date objects.

It is useful for form and user input data. 

from datetime import datetime

date_str = "05-05-2026"

date_obj = datetime.strptime(date_str, "%d-%m-%Y")

print(date_obj)
Output
2026-05-05 00:00:00

Date Difference

Dates can be subtracted to find day differences.

Python returns the result in days and time. 

from datetime import datetime

d1 = datetime(2026, 5, 1)
d2 = datetime(2026, 5, 5)

diff = d2 - d1

print(diff.days)
Output
4

Add Days to Date

The timedelta class adds or subtracts days.

It helps calculate future dates. 

from datetime import datetime, timedelta

today = datetime.now()

future = today + timedelta(days=7)

print(future)
Output
Date after 7 days

Real Use (Timestamp Logger)

Date and time are used in logs and activity tracking systems.

Each event gets a timestamp. 

from datetime import datetime

log_time = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

print("Logged at:", log_time)
Output
Logged at: 2026-05-05 12:30:45

Mini Project (Age Calculator)

Date calculations can find user age easily.

Birth year is compared with the current year. 

from datetime import datetime

birth = datetime(2000, 1, 1)
today = datetime.now()

age = today.year - birth.year

print("Age:", age)
Output
Age: 26

Advantages

Date and time tools improve scheduling and tracking systems.

They are widely used in real-world applications.
