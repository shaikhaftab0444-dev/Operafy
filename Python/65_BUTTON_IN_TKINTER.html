Button in Tkinter

Buttons are used to perform actions when the user clicks on them.

Tkinter buttons can run functions using the command option.

Button Click Example

The following program creates a button and runs a function when clicked. 

import tkinter as tk

def hello():
    print("Button Clicked")

window = tk.Tk()

button = tk.Button(
    window,
    text="Click Me",
    command=hello
)

button.pack()

window.mainloop()
Output

Code Explanation

✔ Button() → Creates button

✔ text → Button text

✔ command → Function runs on click

✔ pack() → Displays widget on window

Take User Input

The Entry widget is used to take input from the user.

The get() method reads the entered value. 

import tkinter as tk

def show():
    name = entry.get()
    print(name)

window = tk.Tk()

entry = tk.Entry(window)
entry.pack()

button = tk.Button(
    window,
    text="Show",
    command=show
)

button.pack()

window.mainloop()
Output

Real Use

Buttons and input fields are used in login forms, calculators, search systems, and registration forms.

User actions trigger functions through button click events.

Task 2: Attach a event handler callback function to Button `command` parameter.

Goal: Build practical skills with Tkinter Button Widget.
💡 Show Solution 
import tkinter
def on_click():
    print('Button Was Clicked!')

root = tkinter.Tk()
btn = tkinter.Button(root, text='Click Me', command=on_click)
btn.pack()
root.withdraw()
print('Callback Connected')
Output
Callback Connected
