Tkinter (Python GUI)

Tkinter is the standard GUI library in Python used to create desktop applications.

It helps create windows, buttons, labels, input boxes, and graphical interfaces easily.

What is Tkinter?

Tkinter is a built-in Python module for creating GUI applications.

It is simple, lightweight, and beginner-friendly.

What is GUI?

GUI stands for Graphical User Interface.

GUI applications use windows, buttons, menus, and input fields instead of command-line text.

✔ Calculator
✔ Login Form
✔ Desktop Software
✔ Student Management Apps

Install Tkinter

Tkinter is usually included with Python by default.

In most systems, no separate installation is required. 

python --version
✔ If Python is installed, Tkinter is mostly available automatically.

Check Tkinter Working

Import the tkinter module to verify that Tkinter is installed correctly. 

import tkinter

print("Tkinter Working")
Output
Tkinter Working

Real Use

Tkinter is used for building desktop applications like calculators, billing systems, form applications, and management software.

Python GUI programs become interactive using buttons, inputs, and event handling.

Practice Exercises

Task 1: Import `tkinter` module and check Tk GUI version.

Goal: Practice fundamental Tkinter GUI concepts.
💡 Show Solution 
import tkinter
print('Tk Version:', tkinter.TkVersion >= 8.6)
Output
Tk Version: True
Task 2: Create basic main Tkinter window object `root = tkinter.Tk()` and set title.

Goal: Build practical skills with Tkinter GUI.
💡 Show Solution 
import tkinter
root = tkinter.Tk()
root.title('GUI Application')
root.withdraw()
print('Tk Window Initialized')
Output
Tk Window Initialized
Task 3: Set window background color using `root.configure(bg='navy')`.

Goal: Deepen your understanding of Tkinter GUI.
💡 Show Solution 
import tkinter
root = tkinter.Tk()
root.configure(bg='navy')
root.withdraw()
print('Background Set')
Output
Background Set
