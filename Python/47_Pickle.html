Pickle in Python

Pickle is used to save Python objects into files.

Saved data can be loaded again later.

Save Data using dump()

The dump() function stores Python data into a binary file.

Lists, dictionaries, and objects can be saved. 

import pickle

data = {"name": "Ali", "marks": 80}

with open("data.pkl", "wb") as file:
    pickle.dump(data, file)
Output
Data Saved in Binary File

Load Data using load()

The load() function reads saved pickle data.

It converts file data back into Python objects. 

import pickle

with open("data.pkl", "rb") as file:
    data = pickle.load(file)

print(data)
Output
{'name': 'Ali', 'marks': 80}

Store List Data

Pickle can save list data easily.

The complete list is stored in binary format. 

import pickle

numbers = [1, 2, 3]

with open("list.pkl", "wb") as file:
    pickle.dump(numbers, file)
Output
List Saved

Real Use (Game Score)

Pickle is useful for saving game scores and app data.

Data remains available after program restart. 

import pickle

score = {"player": "Ali", "score": 100}

with open("score.pkl", "wb") as file:
    pickle.dump(score, file)
Output
Game Score Saved

Important Note ⚠️

Pickle files are not human readable.

Unknown pickle files should not be loaded for security reasons.

Advantages

Pickle saves complex Python data easily.

It is fast and useful for local storage.
