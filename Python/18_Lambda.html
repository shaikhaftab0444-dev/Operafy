Lambda Functions in Python

Lambda Functions are small anonymous functions created using the lambda keyword in Python.

They are mainly used for short operations where writing a complete function using def is not necessary.

Basic Lambda Function

A basic lambda function can accept parameters and return a result in a single line of code.

Lambda functions are commonly used for simple mathematical and logical operations. 

add = lambda a, b: a + b

print(add(5, 3))
Output
8

Lambda with Single Argument

Lambda functions can also work with a single parameter.

This type of function is useful for quick calculations such as square, cube, or conversion operations. 

square = lambda x: x * x

print(square(4))
Output
16

Lambda inside Function

Python allows lambda functions to be returned from another function.

This technique is useful for creating dynamic and reusable operations. 

def multiplier(n):
    return lambda x: x * n

double = multiplier(2)
print(double(5))
Output
10

Lambda with List (map)

The map() function applies a lambda function to every item in a list.

It is commonly used for transforming or modifying list values efficiently. 

numbers = [1, 2, 3, 4]

result = list(map(lambda x: x * 2, numbers))

print(result)
Output
[2, 4, 6, 8]

Lambda with Filter

The filter() function is used to select specific elements from a list based on a condition.

Lambda functions make filtering operations short and easy to understand. 

numbers = [1, 2, 3, 4, 5]

result = list(filter(lambda x: x % 2 == 0, numbers))

print(result)
Output
[2, 4]

Lambda with Sorted (Real Use)

Lambda functions are often used with the sorted() function for custom sorting.

This is useful in real-world applications such as sorting student marks, prices, or records. 

students = [
    {"name": "Ali", "marks": 80},
    {"name": "Sara", "marks": 90},
    {"name": "John", "marks": 70}
]

sorted_list = sorted(students, key=lambda x: x["marks"])

print(sorted_list)
Output
[{'name': 'John', 'marks': 70}, {'name': 'Ali', 'marks': 80}, {'name': 'Sara', 'marks': 90}]

Lambda with Multiple Conditions

Lambda functions can also include conditional expressions.

This allows programs to perform quick decision-making operations in a single line. 

check = lambda x: "Even" if x % 2 == 0 else "Odd"

print(check(5))
Output
Odd

Practice Exercises

Task 1: Write a lambda function `square` that computes the square of an exam mark.

Goal: Syntax of single-line lambda function.
💡 Hint: Use `lambda x: x * x`.
💡 Show Solution 
square = lambda x: x * x
print('Square of 9:', square(9))
Output
Square of 9: 81
Explanation: Lambda functions are compact single-expression anonymous functions defined with `lambda` keyword.
Task 2: Write a lambda function `is_passing` returning True if score >= 50, else False.

Goal: Conditional logic inside lambda expressions.
💡 Hint: Use inline ternary expression `lambda x: True if x >= 50 else False`.
💡 Show Solution 
is_passing = lambda score: score >= 50
print('Score 65 Passing:', is_passing(65))
print('Score 42 Passing:', is_passing(42))
Output
Score 65 Passing: True
Score 42 Passing: False
Explanation: Boolean comparison operators inside lambda return True/False directly without explicit if keyword.
Task 3: Sort a list of student records `[('Ali', 78), ('Sara', 95), ('Bilal', 88)]` by exam marks using sorted() and lambda key.

Goal: Pass lambda as key function to sorted().
💡 Hint: Use `key=lambda student: student[1]` inside sorted().
💡 Show Solution 
students = [('Ali', 78), ('Sara', 95), ('Bilal', 88)]
sorted_students = sorted(students, key=lambda s: s[1])
print('Sorted by Marks:', sorted_students)
Output
Sorted by Marks: [('Ali', 78), ('Bilal', 88), ('Sara', 95)]
Explanation: The lambda function extracts index 1 (marks) from each tuple to determine sort order.
