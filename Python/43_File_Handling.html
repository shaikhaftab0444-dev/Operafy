File Handling in Python

File handling is used to read and write data in files.

Python can create, update, and manage files easily.

Write to File

The w mode writes data into a file.

If the file does not exist, Python creates it. 

file = open("data.txt", "w")

file.write("Hello World")

file.close()
Output
File Created & Text Written

Read from File

The r mode reads file content.

The read() function gets all text. 

file = open("data.txt", "r")

content = file.read()
print(content)

file.close()
Output
Hello World

Append to File

The a mode adds new data to a file.

Old data remains safe. 

file = open("data.txt", "a")

file.write("\nNew Line Added")

file.close()
Output
Text Appended

Read Line by Line

Loops can read files line by line.

This is useful for large files. 

file = open("data.txt", "r")

for line in file:
    print(line)

file.close()
Output
Hello World
New Line Added

Using with Statement

The with statement closes files automatically.

It is the best and safest method. 

with open("data.txt", "r") as file:
    content = file.read()
    print(content)
Output
Hello World
New Line Added

Real Use (Save User Data)

File handling is used to save user records and logs.

Data can be stored permanently in text files. 

name = "Ali"
age = 20

with open("users.txt", "a") as file:
    file.write(name + "," + str(age) + "\n")
Output
User Data Saved in File

Mini Project (Read Users)

Files can store and display user information.

This is useful in real applications and systems. 

with open("users.txt", "r") as file:
    for line in file:
        name, age = line.strip().split(",")
        print("Name:", name, "Age:", age)
Output
Name: Ali Age: 20

Advantages

File handling helps save and manage data permanently.

It is important for real-world applications.

Practice Exercises

Task 1: Create a file 'notes.txt' and write 2 lines of study notes using with open('notes.txt', 'w') as f:.

Goal: Write text files safely with context managers.
💡 Hint: Use 'w' mode with f.write().
💡 Show Solution 
with open('notes.txt', 'w') as f:
    f.write('Python Lesson 1: Basics\nPython Lesson 2: Control Flow')
print('Notes Written Successfully')
Output
Notes Written Successfully
Explanation: Context manager with open() automatically closes the file after writing operations complete.
Task 2: Read and display all lines from 'notes.txt' using .read().

Goal: Read full text file contents.
💡 Hint: Use 'r' mode with f.read().
💡 Show Solution 
with open('notes.txt', 'r') as f:
    content = f.read()
print('File Content:\n' + content)
Output
File Content:
Python Lesson 1: Basics
Python Lesson 2: Control Flow
Explanation: The .read() method returns the entire content of the file as a string.
Task 3: Append a new line 'Python Lesson 3: Functions' to 'notes.txt' using 'a' mode and verify content length.

Goal: Append data without overwriting existing contents.
💡 Hint: Use 'a' append mode with f.write().
💡 Show Solution 
with open('notes.txt', 'a') as f:
    f.write('\nPython Lesson 3: Functions')
with open('notes.txt', 'r') as f:
    lines = f.readlines()
print('Total Lines in Notes:', len(lines))
Output
Total Lines in Notes: 3
Explanation: Mode 'a' appends new data to the end of an existing file without wiping existing text.
