Arithmetic Operators in Python

Arithmetic Operators are used to perform mathematical operations on numbers in Python. These operators allow programmers to carry out basic calculations such as addition, subtraction, multiplication, and division.

Arithmetic operators are commonly used in programs that involve calculations, formulas, billing systems, marksheets, and other number-related tasks.

Common Arithmetic Operators

Operator Name Purpose Example
+ Addition Adds two numbers 10 + 5 = 15
- Subtraction Subtracts one number from another 10 - 5 = 5
* Multiplication Multiplies two numbers 10 * 5 = 50
/ Division Divides one number by another 10 / 5 = 2

In the following programs, we will learn how to use Arithmetic Operators in Python with simple examples.

Addition of Two Numbers

The addition operator (+) is used to add two or more numbers together.

The result of the addition operation can be stored in a variable and displayed using the print() function. 

a = 10
b = 20

c = a + b

print("Addition =", c)
Output
Addition = 30

Subtraction of Two Numbers

The subtraction operator (-) is used to subtract one number from another.

Subtraction is commonly used in calculations involving difference, balance, and remaining values. 

a = 10
b = 3

print("Subtraction =", a - b)
Output
Subtraction = 7

Multiplication of Two Numbers

The multiplication operator (*) is used to multiply numbers in Python.

Multiplication is useful in calculations such as totals, products, and repeated addition. 

a = 10
b = 3

print("Multiplication =", a * b)
Output
Multiplication = 30

Division of Two Numbers

The division operator (/) is used to divide one number by another.

In Python, division usually returns the result as a decimal value. 

a = 10
b = 3

print("Division =", a / b)
Output
Division = 3.3333333333333335

Practice Exercises

Task 1: Calculate sum and average of two exam marks 45 and 49 using `+` and `/`.

Goal: Use basic addition and division operators.
💡 Hint: Group addition inside parentheses before division.
💡 Show Solution 
m1 = 45
m2 = 49
total = m1 + m2
avg = total / 2
print('Total:', total, '| Average:', avg)
Output
Total: 94 | Average: 47.0
Explanation: Parentheses ensure addition completes before division is evaluated.
Task 2: 75 library books are packed into boxes holding 8 books each. Find full boxes (`//`) and leftover books (`%`).

Goal: Use floor division and modulo operators.
💡 Hint: Use `//` for whole boxes and `%` for remainder.
💡 Show Solution 
books = 75
capacity = 8
full_boxes = books // capacity
leftover = books % capacity
print('Full Boxes:', full_boxes, '| Leftover:', leftover)
Output
Full Boxes: 9 | Leftover: 3
Explanation: Floor division `//` returns whole Quotient, while modulo `%` returns the remainder.
Task 3: Calculate 2 raised to power 8 (2^8) using exponentiation operator `**`.

Goal: Use exponentiation operator.
💡 Hint: Use `2 ** 8`.
💡 Show Solution 
base = 2
exp = 8
result = base ** exp
print('2^8 =', result)
Output
2^8 = 256
Explanation: The `**` operator calculates exponentiation power.
