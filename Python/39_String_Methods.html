String Methods in Python

String methods are built-in functions used for text handling.

They help modify, split, and combine strings.

replace() Method

The replace() method changes old text into new text.

It is used for text editing and cleaning. 

text = "Hello World"

new_text = text.replace("World", "Python")

print(new_text)
Output
Hello Python

split() Method

The split() method breaks a string into a list.

It separates data using a specific symbol. 

text = "apple,banana,mango"

data = text.split(",")

print(data)
Output
['apple', 'banana', 'mango']

join() Method

The join() method combines list items into one string.

It joins data using a separator. 

items = ["apple", "banana", "mango"]

text = "-".join(items)

print(text)
Output
apple-banana-mango

Real Use (User Input)

The split() method is useful for processing user input data.

It helps separate names, numbers, and records. 

data = "Ali,Sara,John"

names = data.split(",")

for n in names:
    print(n)
Output
Ali
Sara
John

Clean Data

The replace() method can clean unwanted symbols.

After cleaning, split() can organize the data. 

text = "apple | banana | mango"

clean = text.replace(" | ", ",")
data = clean.split(",")

print(data)
Output
['apple', 'banana', 'mango']

Format Output

The join() method creates clean formatted output.

It is useful for displaying lists as text. 

names = ["Ali", "Sara"]

result = ", ".join(names)

print("Students:", result)
Output
Students: Ali, Sara

Advantages

String methods make text handling simple and fast.

They are widely used in real-world applications.
