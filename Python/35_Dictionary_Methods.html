Dictionary Methods in Python

Dictionary methods are built-in functions used to work with dictionary data.

They help in data access and safe handling.

values() Method

The values() method returns all dictionary values.

It gives only values without keys.

lues() → Get All Values 
student = {
    "name": "Ali",
    "marks": 80
}

print(student.values())
Output
dict_values(['Ali', 80])

items() Method

The items() method returns keys and values together.

It is mostly used inside loops. 

student = {
    "name": "Ali",
    "marks": 80
}

for key, value in student.items():
    print(key, value)
Output
name Ali
marks 80

get() Method

The get() method safely accesses dictionary values.

It does not show an error if the key is missing. 

student = {
    "name": "Ali"
}

print(student.get("name"))
print(student.get("age"))
Output
Ali
None

get() with Default Value

A default value can be returned if the key does not exist.

This helps avoid missing data problems. 

student = {
    "name": "Ali"
}

print(student.get("age", 0))
Output
0

Real Use (API Data Handling )

Dictionary methods are commonly used in APIs and applications.

They help safely manage user and server data. 

data = {
    "user": "Ali",
    "email": "ali@mail.com"
}

print(data.get("phone", "Not Available"))
Output
Not Available

Loop with items()

The items() method is useful for looping through key-value pairs.

It makes dictionary processing easy. 

marks = {
    "Ali": 80,
    "Sara": 90
}

for name, score in marks.items():
    if score > 85:
        print(name)
Output
Sara
