Remaining Arithmetic Operators in Python

Python provides some additional arithmetic operators for performing special mathematical operations. These operators are commonly used in calculations, programming logic, and number-based applications.

The remaining arithmetic operators include floor division, modulus, and exponentiation.

Operator Name Purpose Example
// Floor Division Divides numbers and returns only the whole number part. 10 // 3 = 3
% Modulus Returns the remainder after division. 10 % 3 = 1
** Exponent Raises a number to the power of another number. 2 ** 3 = 8

Floor Division of Two Numbers

The floor division operator (//) is used to divide two numbers and return only the whole number part of the result.

It removes the decimal value and gives the integer quotient. 

a = 10
b = 3

print("Floor Division =", a // b)
Output
Floor Division = 3

Modulus (Remainder) of Two Numbers

The modulus operator (%) is used to find the remainder after division.

It is commonly used in programs related to even-odd checking, calculations, and logical conditions. 

a = 10
b = 3

print("Modulus =", a % b)
Output
Modulus = 1

Exponent (Power) of Two Numbers

The exponent operator (**) is used to calculate the power of a number.

It raises the first number to the power of the second number. 

a = 2
b = 3

print("Exponent =", a ** b)
Output
Exponent = 8

Practice Exercises

Task 1: Check if character `'a'` exists in subject string `'Math'` using `in` operator.

Goal: Check substring membership.
💡 Hint: Use `'a' in 'Math'`.
💡 Show Solution 
subject = 'Math'
print('a' in subject)
Output
True
Explanation: The `in` operator checks whether a substring exists inside target text.
Task 2: Compare two separate lists of student names `['Ali', 'Sara']` with identical items using `is` identity operator.

Goal: Distinguish identity `is` from equality `==`.
💡 Hint: Create two distinct list objects with identical contents and use `is`.
💡 Show Solution 
list1 = ['Ali', 'Sara']
list2 = ['Ali', 'Sara']
print('Equality ==:', list1 == list2)
print('Identity is:', list1 is list2)
Output
Equality ==: True
Identity is: False
Explanation: The `==` operator checks value equality, while `is` checks whether both variables reference the exact same object in memory.
Task 3: Check if student roll number `105` is NOT present in list of present students `[101, 102, 103, 104]` using `not in`.

Goal: Verify non-membership in collections.
💡 Hint: Use `105 not in present_students`.
💡 Show Solution 
present_students = [101, 102, 103, 104]
roll_no = 105
print('Is Absent:', roll_no not in present_students)
Output
Is Absent: True
Explanation: The `not in` operator returns True when target element is absent from collection.
