MySQL Operations in Python

MySQL operations are used to insert, update, delete, and fetch data from databases using Python.

Python sends SQL queries through the cursor object to manage records.

Create Database

A database is used to store related tables and records. 

import mysql.connector

mydb = mysql.connector.connect(
    host="localhost",
    user="root",
    password=""
)

mycursor = mydb.cursor()

mycursor.execute("CREATE DATABASE testdb")

print("Database Created")
Output
Database Created

Create Table

Tables are used to store records inside the database. 

import mysql.connector

mydb = mysql.connector.connect(
    host="localhost",
    user="root",
    password="",
    database="testdb"
)

mycursor = mydb.cursor()

sql = """
CREATE TABLE students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50),
    age INT
)
"""

mycursor.execute(sql)

print("Table Created")
Output
Table Created

Insert Data

The INSERT query adds new records into a table. 

import mysql.connector

mydb = mysql.connector.connect(
  host="localhost",
  user="root",
  password="",
  database="testdb"
)

mycursor = mydb.cursor()

sql = "INSERT INTO students (name, age) VALUES (%s, %s)"
val = ("Ali", 20)

mycursor.execute(sql, val)
mydb.commit()

print(mycursor.rowcount, "record inserted.")
Output
1 record inserted.

Insert Multiple Records

The executemany() method inserts multiple records together. 

import mysql.connector

mydb = mysql.connector.connect(
  host="localhost",
  user="root",
  password="",
  database="testdb"
)

mycursor = mydb.cursor()

sql = "INSERT INTO students (name, age) VALUES (%s, %s)"

values = [
    ("Ali", 20),
    ("Ahmed", 22),
    ("Sara", 19)
]

mycursor.executemany(sql, values)
mydb.commit()

print(mycursor.rowcount, "records inserted.")
Output
3 records inserted.

Read Records (SELECT)

The SELECT query fetches records from the database table. 

import mysql.connector

mydb = mysql.connector.connect(
  host="localhost",
  user="root",
  password="",
  database="testdb"
)

mycursor = mydb.cursor()
mycursor.execute("SELECT * FROM students")

result = mycursor.fetchall()

for row in result:
    print(row)
Output
('Ali', 20)
('Ahmed', 22)
('Sara', 19)

Update Record

The UPDATE query modifies existing records. 

import mysql.connector

mydb = mysql.connector.connect(
  host="localhost",
  user="root",
  password="",
  database="testdb"
)

mycursor = mydb.cursor()
sql = "UPDATE students SET age = 25 WHERE name = 'Ali'"

mycursor.execute(sql)
mydb.commit()

print(mycursor.rowcount, "record updated.")
Output
1 record updated.

Delete Record

The DELETE query removes records from the table. 

import mysql.connector

mydb = mysql.connector.connect(
  host="localhost",
  user="root",
  password="",
  database="testdb"
)

mycursor = mydb.cursor()

sql = "DELETE FROM students WHERE name = 'Ali'"

mycursor.execute(sql)
mydb.commit()

print(mycursor.rowcount, "record deleted.")
Output
1 record deleted.

Drop Table

The DROP TABLE query permanently deletes a table. 

import mysql.connector

mydb = mysql.connector.connect(
  host="localhost",
  user="root",
  password="",
  database="testdb"
)

mycursor = mydb.cursor()

mycursor.execute("DROP TABLE students")

print("Table Deleted")
Output
Table Deleted
