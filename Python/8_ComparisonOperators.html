Comparison Operators

Comparison Operators are used to compare two values in Python. These operators return the result in the form of True or False.

Comparison operators are commonly used in conditions, decision-making statements, loops, and logical operations in programs.

Operator Name Purpose Example
> Greater Than Checks if the left value is greater than the right value. 10 > 5 = True
< Less Than Checks if the left value is smaller than the right value. 5 < 10 = True
== Equality Checks if both values are equal. 5 == 5 = True
!= Not Equal Checks if both values are different. 5 != 3 = True
>= Greater Than or Equal To Checks if the left value is greater than or equal to the right value. 10 >= 10 = True
<= Less Than or Equal To Checks if the left value is smaller than or equal to the right value. 5 <= 10 = True

Check Greater Number

The greater than operator (>) checks whether the first value is greater than the second value.

If the condition is true, Python returns True; otherwise, it returns False. 

a = 10
b = 5

print(a > b)
Output
True

Check Smaller Number

The less than operator (<) checks whether the first value is smaller than the second value.

It is commonly used in comparisons and conditional statements. 

a = 10
b = 5

print(a < b)
Output
False

Check Equality

The equality operator (==) checks whether two values are equal.

If both values are the same, the result will be True. 

a = 10
b = 10

print(a == b)
Output
True

Check Not Equal

The not equal operator (!=) checks whether two values are different from each other.

If the values are not equal, Python returns True. 

a = 10
b = 5

print(a != b)
Output
True

Check Greater or Equal

The greater than or equal to operator (>=) checks whether the first value is greater than or equal to the second value.

This operator combines both greater-than and equality comparison. 

a = 10
b = 10

print(a >= b)
Output
True

Check Less or Equal

The less than or equal to operator (<=) checks whether the first value is smaller than or equal to the second value.

It is useful when comparing ranges and limits in programs. 

a = 10
b = 20

print(a <= b)
Output
True

Practice Exercises

Task 1: Check if student score of 85 is greater than or equal to passing mark 50 using `>=`.

Goal: Evaluate basic numeric comparison.
💡 Hint: Use `score >= 50`.
💡 Show Solution 
score = 85
print('Passed:', score >= 50)
Output
Passed: True
Explanation: Comparison operator `>=` returns boolean True when left operand is greater than or equal to right.
Task 2: Check if two student answer strings `ans1 = 'Paris'` and `ans2 = 'paris'` are equal using `==`.

Goal: Compare text strings for equality.
💡 Hint: Use `ans1 == ans2`.
💡 Show Solution 
ans1 = 'Paris'
ans2 = 'paris'
print('Answers Match:', ans1 == ans2)
Output
Answers Match: False
Explanation: String comparison in Python is case-sensitive, so `'Paris'` does not equal `'paris'`.
Task 3: Check if student's attendance percentage 72% is NOT equal to 100% using `!=` operator.

Goal: Evaluate inequality operator.
💡 Hint: Use `attendance != 100`.
💡 Show Solution 
attendance = 72
print('Needs Improvement:', attendance != 100)
Output
Needs Improvement: True
Explanation: The `!=` operator evaluates to True when operands are not equal.
