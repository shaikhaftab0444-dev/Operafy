finally Block in Python

The finally block always runs.

It works whether an error happens or not.

Basic finally Example

The finally block runs after the try block.

It executes every time. 

try:
    print("Try Block")

finally:
    print("Always Runs")
Output
Try Block
Always Runs

finally with Error

Even if an exception occurs, the finally block still runs.

It is useful for cleanup tasks. 

try:
    x = 10 / 0

except:
    print("Error Occurred")

finally:
    print("Cleanup Done")
Output
Error Occurred
Cleanup Done

File Handling with finally

The finally block safely closes files.

This prevents resource leaks. 

try:
    file = open("data.txt", "r")
    content = file.read()
    print(content)

except:
    print("File Error")

finally:
    file.close()
    print("File Closed")
Output
File Closed

finally with return

The finally block runs even after a return statement.

Cleanup code still executes properly. 

def test():
    try:
        return "From Try"
    
    finally:
        print("Finally Runs")

print(test())
Output
Finally Runs
From Try

finally Override Return ⚠️

A return inside finally overrides the try return value.

This should be used carefully. 

def test():
    try:
        return "Try"
    
    finally:
        return "Finally"

print(test())
Output
Finally

Real Use (Database Connection)

The finally block closes database and network connections.

It keeps systems safe and stable. 

connection = "DB Connected"

try:
    print("Working with DB")

finally:
    connection = None
    print("DB Closed")
Output
Working with DB
DB Closed

Advantages

The finally block ensures cleanup code always runs.

It improves program safety and reliability.
