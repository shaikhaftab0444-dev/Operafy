Tuple vs List in Python

Both Lists and Tuples are collection data types in Python used to store multiple values. However, they differ in mutability, syntax, performance, and usage.

Lists are flexible and changeable, while tuples are fixed and secure. Choosing the correct data type depends on the program requirements.

Basic Difference

A List is mutable, which means its elements can be modified after creation.

A Tuple is immutable, meaning its elements cannot be changed once created.

List Example (Mutable)

Lists allow adding, removing, and updating elements dynamically.

This makes lists suitable for applications where data changes frequently. 

numbers = [1, 2, 3]

numbers[0] = 10

print(numbers)
Output
[10, 2, 3]

Tuple Example (Immutable)

Tuples do not allow modification of elements after creation.

Python generates an error if a program tries to change tuple values. 

nums = (1, 2, 3)

nums[0] = 10
Output
Error ❌ ('tuple' object does not support item assignment)

Syntax Difference

Lists are created using square brackets [].

Tuples are created using parentheses ().

Performance Difference

Tuples are generally faster than lists because their values remain fixed.

Lists require additional memory and processing for modification operations.

Use Case Difference

Lists are preferred when data needs to be updated frequently.

Tuples are preferred for fixed data that should remain secure and unchanged.

Real Use Example

Lists are commonly used for dynamic collections such as shopping carts and user data.

Tuples are often used for fixed records such as coordinates, configuration values, and constant data. 

# List → dynamic data
cart = ["apple", "banana"]
cart.append("mango")

# Tuple → fixed data
location = (18.52, 73.85)  # latitude, longitude

print(cart)
print(location)
Output
['apple', 'banana', 'mango']
(18.52, 73.85)

Quick Comparison

List:
✔ Mutable
✔ Uses []
✔ Flexible

Tuple:
✔ Immutable
✔ Uses ()
✔ Faster + Safe
