Checkbutton Example in Tkinter

A Checkbutton allows users to select or deselect options inside a GUI application.

It is commonly used for settings, preferences, and multiple-choice selections. 

import tkinter
from tkinter import *

top = tkinter.Tk()

CheckVar1 = IntVar()
CheckVar2 = IntVar()

tkinter.Checkbutton(top,text="Machine Learning",variable=CheckVar1,onvalue=1,offvalue=0).grid(row=0,sticky=W)

tkinter.Checkbutton(top,text="Deep Learning",variable=CheckVar2,onvalue=0,offvalue=1).grid(row=1,sticky=W)

top.mainloop()

Login Form in Tkinter

Tkinter provides Label, Entry, and Checkbutton widgets to create login forms.

Entry widgets are used to take user input such as usernames and passwords. 

import tkinter

# Let's create the Tkinter window

window = tkinter.Tk()

window.title("GUI")

# You will create two text labels:
# 'username' and 'password'

tkinter.Label(window,text="Username").grid(row=0)

# Entry for username input

tkinter.Entry(window).grid(row=0,column=1)

tkinter.Label(window,text="Password").grid(row=1)

tkinter.Entry(window).grid(row=1,column=1)

# Checkbutton across two columns

tkinter.Checkbutton(window,text="Keep Me Logged In").grid(columnspan=2)

window.mainloop()
Output

Button Command Function in Tkinter

Buttons can execute Python functions using the command parameter.

This allows applications to perform actions when the button is clicked. 

import tkinter

# Let's create the Tkinter window

window = tkinter.Tk()

window.title("GUI")

# Creating a function called DataCamp_Tutorial()

def DataCamp_Tutorial():

    tkinter.Label(window,text="GUI with Tkinter!").pack()

tkinter.Button(window,text="Click Me!",command=DataCamp_Tutorial).pack()

window.mainloop()

Message Box in Tkinter

The messagebox module is used to display popup alert boxes and dialog messages.

It can show warnings, information messages, and confirmation dialogs. 

import tkinter
import tkinter.messagebox

# Let's create the Tkinter window

window = tkinter.Tk()

window.title("GUI")

# Create an alert box using messagebox

tkinter.messagebox.showinfo("Alert Message","This is just an alert message!")

# Ask a Yes/No question

response = tkinter.messagebox.askquestion("Tricky Question","Do you love Deep Learning?")

# Display response

if response == "yes":

    tkinter.Label(window,text="Yes, of course I love Deep Learning!").pack()

else:

    tkinter.Label(window,text="No, I don't love Deep Learning!").pack()

window.mainloop()
Output

Display Image in Tkinter

Tkinter supports images using the PhotoImage class.

Images can be displayed inside labels, buttons, or other GUI widgets. 

import tkinter

# Let's create the Tkinter window

window = tkinter.Tk()

window.title("GUI")

# Load an image using PhotoImage
# and store it in a variable

icon = tkinter.PhotoImage(file="CNN.png")

# Display the image inside a label

label = tkinter.Label(window,image=icon)

label.pack()

window.mainloop()

Calculator Using Tkinter

Tkinter can be used to create calculator applications with buttons and input fields.

The calculator performs mathematical operations using button click events and functions. 

from tkinter import *

# Let's create the Tkinter window

window = Tk()

window.geometry("312x400")

window.resizable(0,0)

window.title("Calculator")

# Functions

expression = ""

input_text = StringVar()

def btn_click(item):

    global expression

    expression = expression + str(item)

    input_text.set(expression)

def btn_clear():

    global expression

    expression = ""

    input_text.set("")

def btn_equal():

    global expression

    try:

        result = str(eval(expression))

        input_text.set(result)

        expression = ""

    except:

        input_text.set("Error")

        expression = ""

# Input Frame

input_frame = Frame(window,width=312,height=50,bd=0,highlightbackground="black",highlightthickness=1)

input_frame.pack(side=TOP)

# Input Field

input_field = Entry(input_frame,font=('arial', 18, 'bold'),textvariable=input_text,width=50,bg="#eee",bd=0,justify=RIGHT)

input_field.grid(row=0,column=0)

input_field.pack(ipady=10)

# Buttons Frame

btns_frame = Frame(window,width=312,height=350,bg="grey")

btns_frame.pack()

# First Row

Button(btns_frame,text="C",width=32,height=3,command=btn_clear).grid(row=0,column=0,columnspan=3)

Button(btns_frame,text="/",width=10,height=3,command=lambda: btn_click("/")).grid(row=0,column=3)

# Second Row

Button(btns_frame, text="7", width=10, height=3,
command=lambda: btn_click(7)).grid(row=1, column=0)

Button(btns_frame, text="8", width=10, height=3,
command=lambda: btn_click(8)).grid(row=1, column=1)

Button(btns_frame, text="9", width=10, height=3,
command=lambda: btn_click(9)).grid(row=1, column=2)

Button(btns_frame, text="*", width=10, height=3,
command=lambda: btn_click("*")).grid(row=1, column=3)

# Third Row

Button(btns_frame, text="4", width=10, height=3,
command=lambda: btn_click(4)).grid(row=2, column=0)

Button(btns_frame, text="5", width=10, height=3,
command=lambda: btn_click(5)).grid(row=2, column=1)

Button(btns_frame, text="6", width=10, height=3,
command=lambda: btn_click(6)).grid(row=2, column=2)

Button(btns_frame, text="-", width=10, height=3,
command=lambda: btn_click("-")).grid(row=2, column=3)

# Fourth Row

Button(btns_frame, text="1", width=10, height=3,
command=lambda: btn_click(1)).grid(row=3, column=0)

Button(btns_frame, text="2", width=10, height=3,
command=lambda: btn_click(2)).grid(row=3, column=1)

Button(btns_frame, text="3", width=10, height=3,
command=lambda: btn_click(3)).grid(row=3, column=2)

Button(btns_frame, text="+", width=10, height=3,
command=lambda: btn_click("+")).grid(row=3, column=3)

# Fifth Row

Button(btns_frame, text="0", width=21, height=3,
command=lambda: btn_click(0)).grid(row=4, column=0, columnspan=2)

Button(btns_frame, text=".", width=10, height=3,
command=lambda: btn_click(".")).grid(row=4, column=2)

Button(btns_frame, text="=", width=10, height=3,
command=btn_equal).grid(row=4, column=3)

window.mainloop()

Real Use of Tkinter

Tkinter is widely used to create desktop GUI applications such as calculators, login systems, billing software, and management systems.

It helps developers build user-friendly applications with windows, buttons, forms, and interactive controls.

Advantages of Tkinter

Tkinter is simple, lightweight, and included with Python by default.

It allows developers to quickly create graphical desktop applications without installing extra libraries.
