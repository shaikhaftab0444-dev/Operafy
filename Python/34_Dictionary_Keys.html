Advanced Dictionary in Python

Advanced dictionaries help manage data easily and efficiently.

They are useful in real projects and data handling.

Keys, Values & Items

keys() returns all keys.

values() returns all values.

items() returns both keys and values together. 

data = {"a":1, "b":2}

print(data.keys())
print(data.values())
print(data.items())
Output
dict_keys(['a', 'b'])
dict_values([1, 2])
dict_items([('a', 1), ('b', 2)])

Loop with Key & Value

The items() method helps loop through keys and values together.

It makes dictionary traversal simple. 

data = {"Ali":80, "Sara":90}

for k, v in data.items():
    print(k, v)
Output
Ali 80
Sara 90

Check Key Exists

The in keyword checks if a key exists.

It prevents errors while accessing data. 

data = {"a":10}

if "a" in data:
    print("Found")
Output
Found

Use get() Method

The get() method safely accesses values.

It returns a default value if the key is missing. 

data = {"a":10}

print(data.get("b", "Not Found"))
Output
Not Found

Dictionary Comprehension

Dictionary comprehension creates dictionaries in one line.

It makes code short and clean. 

nums = [1,2,3]

result = {n: n*n for n in nums}

print(result)
Output
{1: 1, 2: 4, 3: 9}

Filter Dictionary

Conditions can filter dictionary data.

Only matching values are stored in the new dictionary. 

marks = {"Ali":80, "Sara":40}

passed = {k:v for k,v in marks.items() if v >= 50}

print(passed)
Output
{'Ali': 80}

Merge Dictionaries

Multiple dictionaries can be combined into one.

The ** operator is used for merging. 

d1 = {"a":1}
d2 = {"b":2}

merged = {**d1, **d2}

print(merged)
Output
{'a': 1, 'b': 2}

Nested Dictionary

A dictionary can store another dictionary inside it.

This helps manage complex structured data. 

students = {
    "Ali": {"marks":80, "age":20}
}

print(students["Ali"]["marks"])
Output
80

Sort Dictionary

Dictionaries can be sorted by values using sorted().

Sorting helps organize data properly. 

data = {"a":3, "b":1, "c":2}

sorted_data = dict(sorted(data.items(), key=lambda x: x[1]))

print(sorted_data)
Output
{'b': 1, 'c': 2, 'a': 3}

Count Frequency

Dictionaries are useful for counting repeated values.

This is commonly used in text and data analysis. 

text = ["a","b","a","c","a"]

freq = {}

for ch in text:
    freq[ch] = freq.get(ch, 0) + 1

print(freq)
Output
{'a': 3, 'b': 1, 'c': 1}

Invert Dictionary

Keys and values can be reversed easily.

This creates a new dictionary with swapped data. 

data = {"a":1, "b":2}

rev = {v:k for k,v in data.items()}

print(rev)
Output
{1: 'a', 2: 'b'}
