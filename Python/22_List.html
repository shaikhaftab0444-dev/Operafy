List Programs in Python

A List is a collection data type in Python used to store multiple values in a single variable. Lists can contain numbers, text, and different types of data together.

Lists are widely used for storing, managing, searching, sorting, and processing collections of data in programs.

Print List Elements

A loop can be used to access and print each element of a list one by one.

This helps programmers process all values stored inside the list. 

numbers = [1, 2, 3, 4, 5]

for n in numbers:
    print(n)
Output
1
2
3
4
5

Find Sum of List

Lists can be used with loops to perform repeated calculations such as finding totals and sums.

This program adds all numbers stored inside the list. 

numbers = [1, 2, 3, 4]

total = 0

for n in numbers:
    total = total + n

print(total)
Output
10

Find Maximum Number

Python provides the max() function to find the largest value in a list.

This function is useful for comparing numbers and finding highest values quickly. 

numbers = [10, 25, 5, 40, 15]

max_num = max(numbers)
print(max_num)
Output
40

Find Minimum Number

The min() function is used to find the smallest value in a list.

It helps identify minimum values from collections of data. 

numbers = [10, 25, 5, 40, 15]

min_num = min(numbers)
print(min_num)
Output
5

Print Even Numbers from List

Conditional statements can be combined with loops to filter specific elements from a list.

This example prints only even numbers stored inside the list. 

numbers = [1, 2, 3, 4, 5, 6]

for n in numbers:
    if n % 2 == 0:
        print(n)
Output
2
4
6

Count Elements in List

The len() function is used to count the total number of elements in a list.

This is useful when working with large collections of data. 

numbers = [1, 2, 3, 4]

count = len(numbers)
print(count)
Output
4

Search Element in List

Python provides the in keyword to search for values inside a list.

The program checks whether a specific element exists in the list or not. 

numbers = [10, 20, 30]

if 20 in numbers:
    print("Found")
else:
    print("Not Found")
Output
Found

Reverse List

The reverse() method is used to reverse the order of list elements.

This operation is useful in data processing and reverse sequence handling. 

numbers = [1, 2, 3, 4]

numbers.reverse()
print(numbers)
Output
[4, 3, 2, 1]

Sort List

The sort() method arranges list elements in ascending order by default.

Sorting helps organize data in a structured and readable format. 

numbers = [40, 10, 30, 20]

numbers.sort()
print(numbers)
Output
[10, 20, 30, 40]

Function with List

Lists can also be passed as arguments to functions.

This allows functions to process multiple values dynamically and efficiently. 

def find_sum(nums):
    total = 0
    for n in nums:
        total = total + n
    return total

print(find_sum([1, 2, 3]))
Output
6

Practice Exercises

Task 1: Create a list of 4 classroom subjects `['Math', 'English', 'Science', 'History']` and print the first and last subject.

Goal: Access list items by positive and negative indexing.
💡 Hint: Index `[0]` accesses first element, `[-1]` accesses last.
💡 Show Solution 
subjects = ['Math', 'English', 'Science', 'History']
print('First Subject:', subjects[0])
print('Last Subject:', subjects[-1])
Output
First Subject: Math
Last Subject: History
Explanation: Python uses 0-based indexing for beginning items and negative indexing for trailing items.
Task 2: Modify the second item in `marks = [70, 65, 80]` to 75, then add a new mark 90 using `.append()`.

Goal: Mutate list elements and append items.
💡 Hint: Use index assignment `marks[1] = 75` and `marks.append(90)`.
💡 Show Solution 
marks = [70, 65, 80]
marks[1] = 75
marks.append(90)
print('Updated Marks:', marks)
Output
Updated Marks: [70, 75, 80, 90]
Explanation: Lists are mutable data structures; elements can be modified or added dynamically.
Task 3: Given `scores = [88, 92, 79, 95, 84]`, find total students, highest score using max(), and lowest score using min().

Goal: Analyze list data using built-in functions.
💡 Hint: Use `len()`, `max()`, and `min()` functions.
💡 Show Solution 
scores = [88, 92, 79, 95, 84]
print('Total Students:', len(scores))
print('Highest Score:', max(scores))
print('Lowest Score:', min(scores))
Output
Total Students: 5
Highest Score: 95
Lowest Score: 79
Explanation: Python provides built-in functions to analyze numerical collections efficiently.
