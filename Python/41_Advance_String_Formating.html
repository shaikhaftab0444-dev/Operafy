Advanced String Formatting in Python

Advanced string formatting creates clean and professional output.

It is useful in reports, invoices, tables, and applications.

Dynamic Formatting

Variables can be inserted directly inside strings using f-strings.

This creates dynamic text output. 

name = "Ali"
marks = 85

print(f"{name} scored {marks} marks")
Output
Ali scored 85 marks

Number Formatting

Large numbers can be formatted using comma separators.

This improves readability. 

salary = 5000000

print(f"Salary: {salary:,}")
Output
Salary: 5,000,000

Percentage Formatting

Decimal values can be shown as percentages.

The .2% format controls percentage display. 

score = 0.87

print(f"Success Rate: {score:.2%}")
Output
Success Rate: 87.00%

Currency Formatting

Currency values can include commas and decimal places.

This is useful for bills and invoices. 

amount = 1250.5

print(f"Total: ₹{amount:,.2f}")
Output
Total: ₹1,250.50

Debug Style Printing

Variables can print with both name and value.

This helps during debugging. 

x = 10
y = 20

print(f"{x=}, {y=}")
Output
x=10, y=20

Formatting List Output

Loops with formatting create numbered lists.

This improves output structure. 

items = ["Pen", "Book", "Bag"]

for i, item in enumerate(items, 1):
    print(f"{i}. {item}")
Output
1. Pen
2. Book
3. Bag

Table Formatting

Alignment formatting creates professional table output.

Useful for marksheets and reports. 

students = [("Ali",85), ("Sara",92), ("John",78)]

print(f"{'Name':<10} {'Marks':>5}")
print("-"*15)

for name, marks in students:
    print(f"{name:<10} {marks:>5}")
Output
Name Marks
---------------
Ali 85
Sara 92
John 78

Real Use (Invoice Generator )

String formatting is widely used in billing systems.

It helps display prices and totals clearly. 

item = "Laptop"
price = 55000
qty = 2

total = price * qty

print(f"Item: {item}")
print(f"Price: ₹{price:,}")
print(f"Quantity: {qty}")
print(f"Total: ₹{total:,}")
Output
Item: Laptop
Price: ₹55,000
Quantity: 2
Total: ₹110,000

Real Use (Progress Bar)

Formatted strings can create progress bars and loading text.

This is useful in applications and tools. 

progress = 75

print(f"Loading: [{'#'*progress}{'.'*(100-progress)}] {progress}%")
Output
Loading: [###########################################################################.........................] 75%

Advantages

Advanced formatting improves readability and presentation.

It makes output clean and professional.
