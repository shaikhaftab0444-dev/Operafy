Operator Overloading in Python

Operator overloading changes operator behavior for custom objects.

Special methods like __add__() are used.

Basic Operator Overloading

Custom classes can define how operators work.

The + operator uses the __add__() method. 

class Number:

    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        return self.value + other.value

a = Number(10)
b = Number(20)

print(a + b)
Output
30

Multiple Operators

Different operators like +, -, and * can be overloaded.

Each operator uses its own special method. 

class Number:

    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        return self.value + other.value

    def __sub__(self, other):
        return self.value - other.value

    def __mul__(self, other):
        return self.value * other.value

a = Number(10)
b = Number(5)

print(a + b)
print(a - b)
print(a * b)
Output
15
5
50

String Style Overloading

Operator overloading can combine custom text objects.

Objects behave like normal strings. 

class Text:

    def __init__(self, text):
        self.text = text

    def __add__(self, other):
        return self.text + " " + other.text

t1 = Text("Hello")
t2 = Text("World")

print(t1 + t2)
Output
Hello World

Comparison Operators

Comparison operators like > use methods such as __gt__().

They compare custom objects easily. 

class Number:

    def __init__(self, value):
        self.value = value

    def __gt__(self, other):
        return self.value > other.value

a = Number(10)
b = Number(5)

print(a > b)
Output
True

Real Use (Shopping Cart)

Operator overloading is useful in shopping and billing systems.

Objects can calculate totals automatically. 

class Item:

    def __init__(self, price):
        self.price = price

    def __add__(self, other):
        return self.price + other.price

item1 = Item(100)
item2 = Item(200)

total = item1 + item2

print("Total:", total)
Output
Total: 300

Advantages

Operator overloading makes objects easier to use.

It improves readability and flexibility.
